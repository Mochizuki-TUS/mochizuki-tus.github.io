固体物理学入門— 結晶の対称性から物性へ —

固体物理学の基礎は，結晶学である．本書は，東京理科大学 先進工学部 マテリアル創成工学科 望月研究室の教材として，結晶構造の記述から出発し，群論という道具を身につけ，その上で固体の物性——格子振動，電子バンド，半導体，誘電性，磁性——へ至る道筋を，一本の線としてたどれるように構成した．第IV部では，その上に半導体デバイスの物理——伝導と散乱，高電界効果，接合と界面，発光，非線形光学——を積み上げる．第V部では，第III部で「互いに独立な粒子」として扱った電子とフォノンが相互作用すると何が起こるかを，準粒子という考え方で読み解く——電子間相互作用と Mott 絶縁体，電子格子相互作用と Cooper 対，フォノン間相互作用と熱膨張・熱伝導，励起子とポーラロン，LO–TO 分裂，光励起とポラリトン，赤外分光・Raman 分光，1次元電子系，ランダム系，そして超伝導．想定読者は，微積分と線形代数，そして初等的な量子力学（Schrödinger方程式を解いたことがある程度）を学んだ学部3年生である．第V部も，第III部を読み終えていれば読めるように書いてあり，線形応答理論や第二量子化は前提にしない．

本書には，はっきりした二つの方針がある．ひとつは，群論を抽象論で終わらせないこと．群論は，定義と定理だけを並べると，恐ろしく抽象的で手触りのないものになる．しかし具体的な点群——たとえば $C_{3v}$ ——をひとつ手元に置いて，その積表を自分で埋め，クラスを自分で分け，指標表を自分で作ってみると，驚くほど見通しがよくなる．本書では，定理を述べたら必ずその場で具体例に当てはめ，例題として手を動かす形にした．

もうひとつは，数式変形を省略しないこと．固体物理学の標準的な教科書は，出発点の式と結論の式だけを示して，その間をすべて読者に委ねることが多い．本書では，その「間」をすべて書く．行間を埋めるために必要な数学は，付録Aの「数学ノート」に自己完結的にまとめてある．

読み方
  • 通読する：第1章から順に読む．第I部（結晶学）と第II部（群論）は互いに支え合っているので，飛ばさずに読むことを勧める．
  • 結晶学だけ知りたい：第1章 → 第2章 → 第3章 → 第4章 → 第5章 → 付録B
  • 群論だけ知りたい：第4章 → 第6章 → 第7章 → 第8章 → 第9章 → 第10章
  • 物性からはじめたい：第3章（逆格子）→ 第13章 → 第15章 → 第16章．対称性の議論が出てきたら第II部に戻る．
  • 半導体デバイスを学びたい：第15章 → 第16章 → 第17章 → 第IV部（第21章から第26章へ順に）．伝導と散乱，高電界効果，接合と界面，発光，非線形光学まで，デバイスの物理を一本の線で追う．光吸収と光起電力（第33章），1次元電子系（第35章），ランダム系（第36章）は第V部で扱う．発光（第25章）と光吸収（第33章）は互いに逆の過程なので，あわせて読むとよい．
  • 第V部（発展編）に進む：第III部を読み終えたら，まず第27章（準粒子入門）を読む．第V部の各章が使う言葉——生成・消滅演算子，ファインマン図の読み方，自己エネルギー（エネルギーのずれと寿命）——はここで用意する．
  • 準粒子と相互作用を学びたい：第27章 → 第28章（電子間相互作用）→ 第29章（電子格子相互作用）→ 第30章（フォノン間相互作用）．固体の 3 種類の相互作用を順に追う．
  • 光と格子を学びたい：第27章 → 第29章 29.2 節 → 第31章（励起子とポーラロン）→ 第32章（LO–TO 分裂）→ 第33章（光励起現象とポラリトン）→ 第34章（赤外分光・Raman 分光）．第31章は第33章 33.7 節（励起子吸収）を，第34章は第10章（分子振動の選択則）を使うので，必要に応じて戻る．
  • 超伝導を学びたい：第15章 → 第27章 → 第29章（とくに 29.6〜29.8 節の電子間引力と Cooper 対）→ 第37章．BCS の転移温度と同じ形の式が第35章 35.1 節（Peierls 転移）に出てくるので，あわせて読むと見通しがよい．
  • 金属と絶縁体の境目を学びたい：第16章 → 第28章（Mott 絶縁体）→ 第36章（Anderson 局在と半導体の Mott 転移）→ 第35章（Peierls 転移）．
  • 第一原理計算でフォノンを扱う：第13章 → 第29章 29.3 節（虚数振動数を有するフォノン）→ 第30章（準調和近似，線幅，熱伝導率）→ 第32章（非解析項補正）→ 第34章 34.8 節（計算と実験の突き合わせ）．
  • 数学に不安がある：付録A（数学ノート）を先に眺めておく．各章から必要な節へリンクしてある．
  • バンド図の横軸（$\Gamma$–$X$–$M$…）が何を意味するのか分からない：付録C（Bloch状態）を先に読む．第11章の群論を飛ばしても読めるように書いてある．
