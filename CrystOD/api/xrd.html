crystod.xrd#

Public powder-diffraction API of CrystOD (the crystod-xrd domain).

Powder X-ray and neutron diffraction patterns of a crystal structure, the Python form of crystod-xrd: the Bragg peaks of a pymatgen Structure for a chosen radiation (a K-alpha doublet such as CuKa with the Ka1 + Ka2 lines in the 2:1 ratio, a single line such as MoKa1, or neutrons of a given wavelength, nuclear scattering only), their broadening into a continuous pattern, the text-table and figure writers the command uses, and the superlattice reflections of a distorted structure indexed on its parent lattice and assigned to parent k points and irreps.

Computing patterns

  • load_structure() – a POSCAR as a pymatgen Structure.

  • compute_xrd_pattern() – the Bragg peaks for one radiation, as an XRDPattern of Peak records (h k l, multiplicity, d, 2theta, intensity, line); radiation="neutron" with a wavelength gives the neutron pattern.

  • radiation_lines() – the lines and wavelengths of a radiation.

Superlattice reflections (crystod-xrd –parent)

  • superlattice_reflections() – the reflection families of a child structure indexed on the parent lattice (fundamental or superlattice), the parent k point of each and the share of each parent irrep of that star, as a SuperlatticePattern of SuperlatticeReflection records with one KPointSummary per k star (diagnostic reflections, first-order extinctions).

  • format_superlattice_pattern(), write_superlattice_table(), plot_superlattice_pattern() – the report, the comma-separated table and the overlaid parent/child patterns the command writes.

Broadening and output

  • smear_pattern() – the peaks broadened with a Lorentzian or Gaussian profile of unit area, as (two_theta, intensity) arrays.

  • write_peak_table() – the comma-separated table crystod-xrd writes.

  • plot_xrd_pattern() – the PDF (or PNG, SVG) with tick marks at the peak positions.

Tables

  • WAVELENGTHS – the line wavelengths (RIETAN-FP manual).

  • KALPHA_DOUBLETS – the doublet compositions.

  • XRAY_TYPES, PEAK_PROFILES, RADIATIONS – the names --xraytype, --peak-profile and --radiation accept.

Usage:

from crystod import xrd
from crystod.examples import example_path

structure = xrd.load_structure(str(example_path("221_PPOSCAR_ScF3")))
pattern = xrd.compute_xrd_pattern(structure, "CuKa", (10, 120))
for peak in pattern.peaks[:3]:
    print(peak.hkl, round(peak.two_theta, 3), round(peak.intensity, 2), peak.line)
two_theta, intensity = xrd.smear_pattern(pattern, "lorentzian", width=0.1)

neutron = xrd.compute_xrd_pattern(structure, radiation="neutron", wavelength=1.5)
superlattice = xrd.superlattice_reflections("221_PPOSCAR_SrTiO3.cif",
                                            "140_PPOSCAR_SrTiO3.cif")
for reflection in superlattice.superlattice[:3]:
    print(reflection.hkl_parent_label, reflection.kname,
          reflection.contributions_label)

Attributes resolve lazily (PEP 562): importing this module is instant and pymatgen and matplotlib load only on first use. Functions report bad input as ValueError through this namespace (the implementation module raises SystemExit, as the command line wants).

crystod.xrd.compute_xrd_pattern(structure, xray_type='CuKa', two_theta_range=(10.0, 120.0), *, min_intensity=0.0, symprec=0.01, structure_name='', radiation='xray', wavelength=None)[source]#

Compute the powder pattern of a structure for one radiation.

This is crystod-xrd -c POSCAR --xraytype TYPE without the files. Each line of the radiation is run through pymatgen’s XRDCalculator (intensities scaled to 100 for the strongest peak); for a doublet the Ka2 peaks are weighted by 1/2 and the two lists are merged in order of 2theta. With radiation="neutron" the single wavelength wavelength is run through NDCalculator instead (nuclear scattering only; xray_type is then not used).

Parameters:

  • structure – A pymatgen.core.Structure (see load_structure()).

  • xray_type (str) – A K-alpha doublet ("CuKa", the default, "MoKa", …) or a single line ("CuKa1", "CuKb", …); XRAY_TYPES lists them, case-insensitively.

  • two_theta_range (tuple[float, float]) – (min, max) in degrees; peaks outside are dropped.

  • min_intensity (float) – Peaks whose scaled intensity is below this percentage are dropped. 0 keeps every reflection (pymatgen’s own default would hide those below 0.001 %).

  • symprec (float) – Tolerance in Angstrom of the space-group determination used for the printed symbol only; the intensities are computed from the structure as given, without symmetrization.

  • structure_name (str) – Name recorded in the result for output names and legends (the CLI passes the file name).

  • radiation (str) – "xray" (default) or "neutron".

  • wavelength (float | None) – The neutron wavelength in Angstrom (required for neutrons, refused for X-rays).

Returns:

The XRDPattern.

Raises:

SystemExit – Unknown radiation name, or a wavelength that does not fit the radiation (ValueError when called through crystod.xrd).

Return type:

XRDPattern

Example

>>> from crystod import xrd
>>> from crystod.examples import example_path
>>> s = xrd.load_structure(str(example_path("221_PPOSCAR_ScF3")))
>>> pattern = xrd.compute_xrd_pattern(s, "CuKa1", (10, 60))
>>> pattern.space_group, len(pattern.peaks)
('Pm-3m', 6)
>>> peak = pattern.peaks[0]
>>> peak.hkl, round(peak.two_theta, 2), round(peak.intensity, 1)
((1, 0, 0), 21.82, 100.0)

Draw the parent and child patterns with the superlattice reflections marked.

The child pattern (black) is drawn over the parent reference pattern (grey), both broadened like crystod-xrd patterns; tick marks below the curves mark the fundamental reflections (grey) and the superlattice reflections coloured by k star, and diagnostic reflections carry the name of their irrep.

  • path (str) – Output file; the extension selects the format.

  • profile (str) – "lorentzian" or "gaussian".

  • width (float) – Profile width in degrees.

  • show (bool) – Open an interactive matplotlib window as well.

Returns:

path.

crystod.xrd.smear_pattern(pattern, profile='lorentzian', width=0.1, npoints=5000, two_theta_range=None)[source]#

Broaden the peaks into a continuous pattern.

Every peak becomes a unit-area profile of the same width scaled by its intensity: a Lorentzian (w/pi) / ((x - x0)^2 + w^2) or a Gaussian exp(-(x - x0)^2 / (2 w^2)) / (w sqrt(2 pi)). The two profiles share the same integrated intensity per peak, so they can be compared directly.

Parameters:

  • pattern (XRDPattern) – The peaks, from compute_xrd_pattern().

  • profile (str) – "lorentzian" (default) or "gaussian".

  • width (float) – The profile parameter w in degrees (Lorentzian half width at half maximum, Gaussian standard deviation); 0.1 by default.

  • npoints (int) – Number of 2theta samples.

  • two_theta_range (tuple[float, float] | None) – The window to sample; the pattern’s own by default.

Returns:

(two_theta, intensity) arrays of length npoints.

Raises:

SystemExit – Unknown profile name or non-positive width (ValueError when called through crystod.xrd).

Return type:

tuple[ndarray[tuple[Any, …], dtype[float64]], ndarray[tuple[Any, …], dtype[float64]]]

crystod.xrd.superlattice_reflections(parent_file, child_file, radiation='xray', xray_type='CuKa', wavelength=None, two_theta_range=(10.0, 120.0), tolerance=0.01, *, min_intensity=0.0)[source]#

Index the powder pattern of a distorted structure on its parent.

This is crystod-xrd --parent PARENT -c CHILD without the files. The two structures are paired by the symmetry-mode analysis; every reflection family of the child in the window is indexed on the parent lattice, classified as fundamental or superlattice, assigned to its parent k star, and (superlattice) split among the irreps of that star.

Parameters:

  • parent_file (str) – High-symmetry structure (CIF or POSCAR).

  • child_file (str) – Distorted structure (CIF or POSCAR) whose primitive cell is an integer multiple of the parent’s.

  • radiation (str) – "xray" (default) or "neutron".

  • xray_type (str) – X-ray line or doublet (XRAY_TYPES); the table uses its first line (Ka1 of a doublet). Not used for neutrons.

  • wavelength (float | None) – Neutron wavelength in Angstrom (required for neutrons, refused for X-rays).

  • two_theta_range (tuple[float, float]) – (min, max) in degrees.

  • tolerance (float) – Symmetry tolerance (Angstrom) of the symmetry-mode analysis and of the child point group.

  • min_intensity (float) – Families weaker than this percentage of the strongest child family are left out of the table (SuperlatticePattern.listed); the k-point summary is built from every family.

Returns:

The SuperlatticePattern.

Raises:

SystemExit – Bad radiation options or window, unreadable files, a child that cannot be mapped onto the parent, or an element without scattering data (ValueError when called through crystod.xrd).

Return type:

SuperlatticePattern

Example

>>> from crystod import xrd
>>> pattern = xrd.superlattice_reflections(
...     "221_PPOSCAR_SrTiO3.cif", "140_PPOSCAR_SrTiO3.cif")
>>> first = pattern.superlattice[0]
>>> first.hkl_parent_label, first.kname, first.contributions_label
('(3 1 1)/2', 'R', 'R5- 100 %')
