crystod.slab#

Public surface-slab API of CrystOD (the crystod-slab domain).

Cut surface slabs from a bulk crystal structure, the Python form of crystod-slab. For each Miller index every distinct termination is built with pymatgen’s SlabGenerator and measured: number of atoms, thickness along the surface normal, vacuum, in-plane area, formula, whether the slab is polar (a nonzero dipole per area from the oxidation states, Slab.is_polar) and whether its two faces are equivalent (Slab.is_symmetric). The slabs are written as VASP POSCAR files.

The bulk structure

  • load_structure() – read a POSCAR (CIF works too), optionally in the standardized conventional cell; conventional_cell() – the standardization on its own.

  • describe_cell() – space group and the comparison with the conventional standard cell, as a CellInfo.

Miller indices

  • parse_miller_index() – "1 0 0", "1,0,0" or a four-index (h k i l) of hexagonal axes, as (h, k, l).

  • read_index_list() – an index list file, one index per line.

  • distinct_miller_indices() – the indices up to a maximum that are distinct under the Laue group of the crystal (in the axes of the cell).

  • format_miller_index() – "(1 0 -1)".

Slabs

  • generate_slabs() – every termination of the given surfaces (or of every distinct surface up to max_index), as a SlabSet of SlabRecord.

  • guess_oxidation_states(), parse_oxidation_states(), resolve_oxidation_states(), format_oxidation_states(), format_charge() – the oxidation states of the polarity test and the net charge of a (symmetrized) slab.

  • format_table(), slab_status() – the table crystod-slab prints (one string; crystod.search.format_table() returns a list of lines) and the status column; table_legend(), TABLE_LEGEND, CHARGE_LEGEND – what its columns mean.

Files

  • write_slab_poscar(), slab_poscar_text(), slab_filename() – the POSCAR files (POSCAR_slab_SrTiO3_111_t1, ..._100_s1 for a symmetrized slab); like crystod.search.write_poscar(), write_slab_poscar returns (path, status) and keeps an identical file, replacing a different one only with overwrite=True.

Constants

  • SLAB_CITATION_LINES – the papers to cite; DEFAULT_SLAB_SIZE, DEFAULT_VACUUM_SIZE, DEFAULT_TOLERANCE – the defaults of the command.

Usage:

from crystod import slab

structure = slab.load_structure("221_PPOSCAR_SrTiO3")
records = slab.generate_slabs(structure, max_index=1)
for record in records:
    print(record.label, record.n_atoms, record.polar, record.symmetric)
print(slab.format_table(records))
slab.write_slab_poscar(records[0])        # ('POSCAR_slab_SrTiO3_111_t1', 'wrote')
records = slab.generate_slabs(structure, miller_index=(1, 0, 0), symmetrize=True)

Attributes resolve lazily (PEP 562): importing this module is instant and pymatgen loads only on first use. Functions report bad input as ValueError through this namespace (the implementation module crystod.surface_slab raises SystemExit, as the command line wants).

crystod.slab.distinct_miller_indices(structure, max_index, tolerance=0.1)[source]#

The Miller indices with |h|, |k|, |l| <= max_index that are distinct under the Laue group of the crystal.

Two indices are the same surface when a rotation of the space group of structure (found by spglib at tolerance), possibly followed by the inversion that turns a slab over, maps one onto the other. This is done in the axes of the cell as given, so it holds for every setting (a primitive rhombohedral cell, a monoclinic cell of pseudo-orthorhombic metric, …). The indices are reduced by their common factor, and the first index of each family is kept in pymatgen’s order (get_symmetrically_distinct_miller_indices: low indices first), with whose list this one agrees for a crystal that is not trigonal and whose lattice has no more symmetry than the crystal. pymatgen merges indices under the symmetry of the lattice (and, for a trigonal crystal, of its hexagonal setting), which on a primitive rhombohedral cell lists one surface twice and misses another, and on a lattice of higher symmetry than the crystal misses surfaces.

Example

>>> from crystod import slab
>>> from crystod.examples import example_path
>>> s = slab.load_structure(example_path("221_PPOSCAR_SrTiO3"))
>>> slab.distinct_miller_indices(s, 1)
[(1, 1, 1), (1, 1, 0), (1, 0, 0)]
Return type:

list[tuple[int, int, int]]

crystod.slab.format_table(records, max_atoms=None, no_polar=False, no_files=False, width=100)[source]#

The slab table crystod-slab prints, one header line and one line per slab.

The columns are # h k l shift atoms thickness vacuum area formula [charge] polar symmetric status (see table_legend(); the charge column only when a slab is charged); the status is slab_status(). The column widths follow the content; when the table would be wider than width columns the units leave the header, then the columns move closer together, then the formulas leave the table for lines of their own (#1 Sr5Ti5O15) below it.

crystod.slab.generate_slabs(structure, miller_index=None, *, max_index=None, slab_size=10.0, vacuum_size=15.0, symmetrize=False, oxidation_states=None, tolerance=0.1, center=True, primitive=True, lll_reduce=False, in_unit_planes=False, max_normal_search=None, orthogonal_c=False)[source]#

Every distinct termination of the given surfaces, measured.

This is crystod-slab without the files. For each index, SlabGenerator(structure, hkl, slab_size, vacuum_size, ...) .get_slabs(symmetrize=symmetrize, tol=0.1, ftol=0.1); the slabs are numbered t1, t2, ... per index in pymatgen’s order (s1, s2, ... with symmetrize).

Parameters:

  • structure – The bulk Structure (see load_structure()); Miller indices refer to its axes.

  • miller_index – One index ((1, 0, 0), "1 0 0", a four-index (1, 0, -1, 0)) or a list of them. Give this or max_index.

  • max_index (int | None) – Every index with |h|, |k|, |l| <= max_index distinct under the Laue group of the crystal (distinct_miller_indices()).

  • slab_size (float) – Minimum slab height in Angstrom (in d_hkl lattice planes with in_unit_planes): whole oriented cells are stacked until they reach it, and the atoms span that height less the gap at the cut.

  • vacuum_size (float) – Minimum vacuum height, likewise in whole cells.

  • symmetrize (bool) – Symmetric slabs: atoms are removed from one face of every asymmetric slab until the faces are equivalent at tolerance (non-stoichiometric, possibly charged: SlabRecord.charge).

  • oxidation_states (dict[str, float] | None) – {"Sr": 2, "Ti": 4, "O": -2} for the dipole; by default pymatgen’s guess, and no polarity (polar = None) when there is none. Given states must balance the bulk.

  • tolerance (float) – Symmetry tolerance in Angstrom of the Laue group of max_index, of Slab.is_symmetric and of the symmetrization.

  • center (bool) – Center the slab in the cell (pymatgen center_slab).

  • primitive (bool) – Reduce the in-plane cell to a primitive one when pymatgen can (it keeps the oriented cell’s a, b otherwise).

  • lll_reduce (bool) – Reduce the in-plane cell to its shortest a, b and make c as perpendicular as whole in-plane vectors allow (a and b stay in the surface).

  • in_unit_planes (bool) – slab_size and vacuum_size count d_hkl lattice planes of the cell (one can hold several atomic layers).

  • max_normal_search (int | None) – pymatgen max_normal_search (a c vector as perpendicular to the surface as possible).

  • orthogonal_c (bool) – Make c perpendicular to the surface (Slab.get_orthogonal_c_slab) before the measurements.

Returns:

The SlabSet (a list of SlabRecord).

Raises:

SystemExit – Both or neither of miller_index and max_index, a bad index, non-positive sizes or tolerance, oxidation states that do not fit the structure, or a slab pymatgen cannot build (ValueError through crystod.slab).

Return type:

SlabSet

Example

>>> from crystod import slab
>>> from crystod.examples import example_path
>>> s = slab.load_structure(example_path("221_PPOSCAR_SrTiO3"))
>>> records = slab.generate_slabs(s, max_index=1)
>>> [(r.miller_index, r.n_atoms, r.polar) for r in records]
[((1, 1, 1), 25, True), ((1, 1, 0), 20, True), ((1, 0, 0), 15, False)]

crystod.slab.load_structure(path, conventional=False, tolerance=0.1)[source]#

Read the bulk structure (POSCAR; CIF and other pymatgen formats work too).

The structure is read by pymatgen in VASP’s reading of a POSCAR (crystod.vasp_io.poscar_structure()), stripped of site properties and oxidation states, and checked to be ordered.

Parameters:

  • path – The structure file.

  • conventional (bool) – Return the standardized conventional cell (SpacegroupAnalyzer.get_conventional_standard_structure) instead of the cell as given; Miller indices then refer to its axes. The sites keep the element order of the file.

  • tolerance (float) – Symmetry tolerance in Angstrom of the standardization.

Returns:

A pymatgen.core.Structure.

Raises:

SystemExit – The file is missing or unreadable, or a site is partially occupied or shared by several species (ValueError through crystod.slab).
