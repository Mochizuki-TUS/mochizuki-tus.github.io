重なり積分 S(R) はどう計算するのか

距離 R だけ離れた 2 つの原子に軌道を 1 つずつ置いたときの 重なり積分 S = ∫φAφB dV を， 講義第 5 回の道筋どおりに計算します． 楕円座標の導入 → 1s–1s の解析解 → σπδ の分類（対称性）→ 一般の軌道の数値計算という一本道です． シミュレーターの中で動いているのは，最後の節の計算そのものです．

0. 重なり積分とは何か

原子 A（原点）と原子 B（z 軸上，距離 R）に，規格化された軌道 φA, φB を 1 つずつ置きます．重なり積分は

S(R)= ∫ φA∗ (r) φB (r) dV = ⟨φA|φB⟩

で定義されます（講義では第 3 回 p.7 で定義だけ先に出てきて，第 5 回で計算します）． これは関数の内積です．ベクトルの内積 a·b = |a||b|cosθ の cosθ にあたるのが S で，Cauchy–Schwarz の不等式から必ず |S| ≤ 1．「2 つの軌道がどれだけ同じ形か」を測る数です．

  • R → 0 で同じ軌道どうしなら S = 1（規格化）．
  • R → 0 で違う軌道どうし（1s と 2s など）なら S = 0（同一中心の正規直交性）．
  • R → ∞ で必ず S → 0（裾が指数関数で切れるから）．
記号の約束：Bohr 半径は a₀ と書きます このページでは原子核 B の添字と紛れないよう，講義第 5 回にならって Bohr 半径を aB ではなく a0 = 0.529 × 10−10 m と書きます． ほかのページの aB とまったく同じものです．

1. まず結論（30 秒版）

  1. 2 中心の積分は球座標では手に負えない（rB が rA と θA の両方に依存する）ので， 2 つの核を焦点とする楕円座標に移る．
  2. 1s–1s（水素）はそのまま手で積分できて，ρ = R/a0 として S = (1 + ρ + ρ²/3)e−ρ．H₂ の平衡距離 ρ = 1.4 で S = 0.753．
  3. 結合軸まわりの量子数 m が一致しない組は，φ 積分の直交性で S = 0． これが σ（m = 0）・π（|m| = 1）・δ（|m| = 2）・φ（|m| = 3）という分類の正体．
  4. 符号には「両方の軌道を同じ座標系で書く」という約束が要る．約束を変えると符号だけ変わる．
  5. 2s 以上の一般の軌道も，同じ楕円座標で指数関数 × 多項式の積分に落ちる． シミュレーターでは Gauss–Legendre 求積で数値計算している（1s–1s の解析解と機械精度で一致）．

2. 楕円座標 ― 2 中心問題の自然な座標

2.1　なぜ球座標では難しいのか

A を原点に置いた球座標 (r, θ, φ) で書くと，φA = φA(r) は簡単ですが， B から測った距離が余弦定理で

rB= r2+R2 −2rR cos⁡θ

と 2 変数の関数になり，e−rB/a0 の積分はそのままでは進みません． そこで座標のほうを問題に合わせます．

2.2　楕円座標の定義（講義第 5 回の記法）

空間の各点で，2 つの核からの距離 rA, rB を測り，

cosh⁡μ= rA+rBR , cos⁡ν= rA−rBR … ①

と置きます（φ は結合軸まわりの回転角のまま）． 「2 点からの距離の和が一定」の面は焦点 A, B の楕円（回転楕円体）， 「差が一定」の面は双曲面です．つまり①は，空間を楕円と双曲線の網の目で 張り替える座標変換です（図 1）．式を軽くするため

ξ=cosh⁡μ ∈[1,∞) , η=cos⁡ν ∈[−1,1]

も使います．①を逆に解くと，2 つの距離はどちらも 1 次式になります．

rA= R2 (ξ+η) , rB= R2 (ξ−η) … ②
この座標が「効く」理由 1s 軌道の積は e−(rA+rB)/a0 = e−ρξ と， ξ だけの関数になります．手に負えなかった 2 中心の指数関数が， 座標を選び直しただけで 1 変数に畳まれる——これが楕円座標を使う理由のすべてです． H₂⁺ の Schrödinger 方程式が（Born–Oppenheimer 近似のもとで）厳密に変数分離できるのも同じ事情です．

2.3　体積要素

ヤコビアンを計算すると（講義第 5 回では (μ, ν) のまま |J| = (R/2)³ sinhμ sinν (sinh²μ + sin²ν) の形）， (ξ, η) では dξ = sinhμ dμ，dη = −sinν dν， sinh²μ + sin²ν = ξ² − η² なので，すっきりした形になります．

dV= (R2)3 (ξ2−η2) dξ dη dφ … ③

図 1｜楕円座標の網の目．実線の楕円が ξ 一定（距離の和が一定）， 破線の双曲線が η 一定（距離の差が一定）．スライダーで点 (ξ, η) を動かして， rA, rB との関係②を確かめてください．

3. 1s–1s を手で積分する ― 講義第 5 回の計算

3.1　積分を楕円座標に書き換える

水素の 1s 軌道（Z′ = 1）を A と B に置きます．

φA= 1πa03 e−rA/a0 , φB= 1πa03 e−rB/a0

積は e−(rA+rB)/a0． ①②③を代入し，ρ = R/a0 と書くと rA + rB = Rξ なので

S= 1πa03 (R2)3 ∫02πdφ ∫1∞dξ ∫−11dη e−ρξ (ξ2−η2)

φ 積分は 2π を出すだけ．η 積分も多項式なので手で済みます （∫ξ²dη = 2ξ²，∫η²dη = 2/3）．残るのは ξ 積分だけです．

S= ρ34 ∫1∞ (2ξ2−23) e−ρξ dξ … ④

3.2　補助積分 Ak(ρ)

④に出てくる「多項式 × 指数関数」の積分には名前が付いています．

Ak(ρ) = ∫1∞ ξk e−ρξ dξ , Ak= e−ρρ + kρ Ak−1

漸化式は部分積分 1 回です．A0 = e−ρ/ρ から順に上げると

A2= e−ρ ( 1ρ+ 2ρ2+ 2ρ3 )

3.3　結果

④に A0 と A2 を入れて整理すると，ρ の負べきがすべて消えて

S(R)= ρ32 (A2−A03) = (1+ρ+ ρ23) e−ρ , ρ=Ra0 … ⑤

検算：ρ → 0 で S → 1（規格化），ρ → ∞ で S → 0．どちらも合格です． 値の感覚をつかむために，いくつか並べておきます．

R / a0 011.42 468
S（1s–1s） 10.8580.7530.586 0.1890.0470.010
H₂ の実感 H₂ の平衡核間距離は R = 1.4 a0 = 74 pm で，そこでは S = 0.75． つまり結合している 2 つの 1s は「75 % 同じ関数」というくらい深く重なっています． 「重なり積分は小さいから無視する」という近似（Hückel 法など）が π 電子系で許されて，H₂ ではあやしい理由がこの数字から見えます．

4. σ・π・δ・φ ― m の選択則

一般の軌道 φ = Rnl(r)Ylm(θ,φ) では， 結合軸（z 軸）まわりの角度 φ への依存性が cos(mφ) または sin(mφ)（実軌道）です． A の軌道が mA，B の軌道が mB なら，重なり積分の φ 部分は

∫02π cos⁡(mAφ) cos⁡(mBφ) dφ = πδmAmB (m>0)

という三角関数の直交性そのものになります（Fourier 級数のページで やった内積です．cos 型と sin 型の組も 0）．つまり m が一致しない組の S は，動径部分を見るまでもなく厳密に 0 です． 一致した組だけが生き残り，その m の値で結合を呼び分けます．

型m重なれる組の例節面（結合軸を含む面）
σ0s–s，s–pz，pz–pz，s–dz²，…0 枚
π±1px–px，px–dxz，dxz–dxz，…1 枚
δ±2dxy–dxy，dx²−y²–dx²−y²，…2 枚
φ±3f–f の一部（4fx(x²−3y²) どうしなど）3 枚
これは群論の選択則のいちばん簡単な例です 講義第 12 回では「⟨φA|Ĥ|φB⟩ がゼロかどうかは， 直積 ΓA ⊗ ΓB に全対称表現が含まれるかで決まる」ことを学びます． 2 原子分子の対称性（結合軸まわりの回転）では既約表現のラベルがちょうど m で， 上の φ 積分の直交性がその選択則の実体です． S と β = ⟨φA|Ĥ|φB⟩ は同じ選択則に従う （Ĥ が全対称だから）ので，「どの軌道どうしが結合できるか」は S で判定できます．

5. 符号の約束ごと

S の符号は，2 つの軌道をどの座標系で書くかという約束に依存します． このシミュレーターでは，A と B の軌道を同じグローバル座標 （z 軸は A → B の向き）で定義しています．このとき：

  • 1s(A)–2pz(B) の σ：B の 2pz は A の側に負のローブを向けるので S < 0． 軌道を入れ替えて 2pz(A)–1s(B) にすると，今度は正のローブが B を向くので S > 0． 大きさは同じで符号だけ反転します．
  • 2pz–2pz の σ：向かい合うローブの符号が逆（＋が−を向く）なので， 遠方では S < 0．一方 R → 0 では同じ軌道なので S → +1． そのあいだの R = 5.03 a0 でちょうど S = 0 になります （負側の最大は |S| = 0.33，R = 8.9 a0）．

量子力学では軌道を −1 倍しても同じ状態なので，符号そのものに物理はありません． 物理があるのは「約束を固定したうえでの相対符号」です．教科書の表 （たとえば Slater–Koster の表や Mulliken の S の一覧表）と比べるときは， まずどちら向きの p 軌道を正としているかを確認してください． 結合性・反結合性（φA ± φB のどちらが下がるか）を決めるのは 共鳴積分 β の符号との組み合わせで，これは第 11 回の永年方程式で扱います．

6. 一般の軌道 ― 数値計算のしくみ（シミュレーターの中身）

6.1　どの組も「指数 × 多項式」に落ちる

有効核電荷 Z′ の水素様軌道の動径部分は，どれも Rnl(r) = e−Z′r/n ×（r の多項式）です． A の減衰率を αA = Z′A/nA， B を αB = Z′B/nB と書くと，②から指数部分は

e −αArA −αBrB = e −pξ−qη , p=R2 (αA+αB) , q=R2 (αA−αB)

一方，多項式部分（rk や cosθA = (1 + ξη)/(ξ + η) を含む角度因子）は， ②を入れるとすべて ξ, η の多項式になります（分母の ξ ± η は rl の因子と約分されます）．つまりどの軌道の組でも

S= ∑j,k cjk Aj(p) Bk(q) , Bk(q)= ∫−11 ηk e−qη dη

という有限和に落とせます（Bk にも部分積分の漸化式があります）． Mulliken らはこの方法で 1s〜3d の主な組の S を式と数表にまとめました（1949 年）．

6.2　シミュレーターでは求積で済ませる

係数 cjk を組ごとに手で整理する代わりに，シミュレーターは ③の 2 重積分を Gauss–Legendre 求積で数値計算しています． 被積分関数が ξ 方向に e−p(ξ−1) で減衰するので， u = p(ξ − 1) に変数変換して 3 区間（0–5, 5–15, 15–45）に分け， 各区間・各方向 24 点で足します．被積分関数は「多項式 × 指数」という 求積に最適な形なので，これだけで解析解⑤と機械精度（15 桁）で一致します． 図 2 で確かめられます．

図 2｜数値計算した S(R) と解析解の照合．実線が数値計算（シミュレーターと同じコード）， 橙の破線が 1s–1s の解析解⑤です．組を切り替えると，1s–2s の「直交から出発する山」や 2p–2p σ の符号反転も見えます．

7. どこで効いてくるか

7.1　永年方程式の分母（第 11 回）

LCAO の試行関数 Ψ = cAψA + cBψB に 変分原理（Lagrange の未定乗数法）を使うと， H₂ 型（αA = αB = α）の結合性・反結合性軌道のエネルギーは

Eb= α+β1+S , Ea= α−β1−S

と，S が分母に入ります（クーロン積分 α，共鳴積分 β． 講義第 11 回は ⟨Ψ|Ψ⟩ = 2 と規格化する流儀なので未定乗数 ε はこの半分， 全エネルギー E = 2ε は同じです）． S ≠ 0 のせいで反結合性軌道の上がり幅は結合性軌道の下がり幅より大きくなります （1 − S < 1 + S）．閉殻どうしを近づけると必ず損（Pauli 反発）になるのは， この非対称のためです．

7.2　STO-3G ― Gauss 関数を使う理由（第 5 回）

ここまで見たとおり，Slater 型（e−ζr）の 2 中心積分は 楕円座標という「重い道具」が要ります．ところが Gauss 型 e−αr² なら， 2 つの Gauss 関数の積が別の 1 つの Gauss 関数になる（Gauss 積の定理）ので， 重なり積分が座標変換なしの初等積分で閉じます． だからこそ量子化学ソフトは 1s を 3 つの Gauss 関数で真似る STO-3G のような基底を使うのでした． 「正しい形（Slater）を，計算しやすい形（Gauss）の和で近似する」—— 第 5 回の STO-3G の導出は，この積分の重さを知ってはじめて動機が分かります．

7.3　バンドへ（固体物理）

原子を鎖に並べると，隣どうしの S と β が準位を帯（バンド）に広げます． S(R) の指数減衰は「最近接だけ考える」タイトバインディング近似の根拠であり， σ と π で S や β の大きさ・符号が違うことが σ バンドと π バンドの幅・向きの違いになります． つづきは「分子軌道からバンドへ」のページでどうぞ．

⚠ よくある誤解 「S が大きい＝結合が強い」ではありません．結合エネルギーを決めるのは β（と電子数）で，S は規格化と Pauli 反発を通じて効く脇役です． また，ここで使った軌道は水素様（1 電子）なので，実際の多電子原子では Hartree–Fock 軌道や数値原子軌道で置き換わりますが， 「指数減衰・直交性・σπδ 分類・符号の約束」という骨格は変わりません．

  • 第 5 回：楕円座標による 1s–1s の手計算（このページの 2–3 節）と STO-3G の導出（7.2 節）．
  • 第 11 回：永年方程式．α, β, S から結合性・反結合性準位（7.1 節）．
