Chapter 8Character Tables — How to Construct and Read Them

In Chapter 7 we obtained the concept of an irreducible representation and the great orthogonality theorem (also called the wonderful orthogonality theorem) that supports it. However, that theorem is a statement about the matrix elements $D^{(i)}(R)_{\mu\nu}$ themselves. Matrices change their appearance depending on the choice of basis, so they are awkward to handle as they stand.

This is where the character comes in. The character is nothing more than the trace of the representation matrix, $\chi(R)=\Tr D(R)$. Yet this “nothing more” quantity does not depend on the choice of basis, and it takes a common value for elements belonging to the same class. In other words, the enormous information contained in $h$ matrices is compressed into a list of numbers, one for each class. This compressed table is the character table.

The centerpiece of this chapter is to construct character tables yourself from scratch. In many textbooks the character table is printed at the back of the book as something “given.” But for a point group as small as $C_{3v}$ or $C_{4v}$, anyone can build it in a few minutes just by writing out the elements of the group, sorting them into classes, and solving the simultaneous equations of the orthogonality relations. Once you can do this, the character table no longer looks like a mere table of numbers but like a map that reflects the structure of the group itself.

And once you can use character tables, the crystal-field splitting of Chapter 10, the classification of molecular vibrations, and selection rules all reduce to a single task: “decompose a given list of characters into irreducible representations.” This is the high point of Part II.

8.1 Definition of the Character — Only the Trace Survives

8.1.1 Definition

Definition: character

For a representation $D$ of a group $G$, the trace of the matrix $D(R)$ corresponding to an element $R\in G$,

$$ \chi(R) \equiv \Tr D(R) = \sum_{\mu=1}^{\ell} D(R)_{\mu\mu} $$

is called the character of $R$. Here $\ell$ is the dimension of the representation. The character of the $i$th irreducible representation $\Gamma^{(i)}$ is written $\chi^{(i)}(R)$.

First, one property that is obvious but important. The representation matrix of the identity element $E$ is the $\ell\times\ell$ identity matrix, so

$$ \begin{equation} \chi(E) = \Tr I_{\ell} = \ell \label{eq:8-chiE} \end{equation} $$

That is, the character of the identity element is the dimension of the representation itself. Looking at the leftmost column of a character table, you can see at once the dimension of each irreducible representation.

8.1.2 The character does not change under a similarity transformation

When the choice of basis is changed, the representation matrix $D(R)$ changes into the form $D'(R)=U^{-1}D(R)U$ (Chapter 7). All the matrix elements change. The trace, however, does not. This is a property we touched on once in the Math Note of Chapter 4, but since it is the linchpin of group theory, we write out the components and prove it here.

Theorem 8.1 (Invariance under similarity transformations)

For any square matrix $D$ and any invertible matrix $U$,

$$ \Tr\left(U^{-1}DU\right) = \Tr D $$

Therefore, equivalent representations (those related by a similarity transformation) have the same character.

Proof: Verifying by writing out all the indices

The components of a matrix product are $(AB)_{\mu\nu}=\sum_\alpha A_{\mu\alpha}B_{\alpha\nu}$. Using this twice, we write out the $(\mu,\mu)$ component of $U^{-1}DU$.

$$ \left(U^{-1}DU\right)_{\mu\mu} = \sum_{\alpha}\sum_{\beta} (U^{-1})_{\mu\alpha}\, D_{\alpha\beta}\, U_{\beta\mu} $$

The trace is the sum of this over $\mu$, so

$$ \Tr\left(U^{-1}DU\right) = \sum_{\mu}\sum_{\alpha}\sum_{\beta} (U^{-1})_{\mu\alpha}\, D_{\alpha\beta}\, U_{\beta\mu} $$

Now we interchange the order of the sums. The three factors are not matrices but just numbers, so we may freely change the order in which they are multiplied. Bringing the sum over $\mu$ to the inside, we obtain

$$ = \sum_{\alpha}\sum_{\beta} D_{\alpha\beta} \left[\sum_{\mu} U_{\beta\mu}(U^{-1})_{\mu\alpha}\right] $$

The expression in square brackets is exactly the $(\beta,\alpha)$ component of the matrix $UU^{-1}$. Since $UU^{-1}=I$,

$$ \sum_{\mu} U_{\beta\mu}(U^{-1})_{\mu\alpha} = (UU^{-1})_{\beta\alpha} = \delta_{\beta\alpha} $$

Substituting this, $\delta_{\beta\alpha}$ collapses the sum over $\beta$ and leaves only $\beta=\alpha$, so

$$ \Tr\left(U^{-1}DU\right) = \sum_{\alpha}\sum_{\beta} D_{\alpha\beta}\,\delta_{\beta\alpha} = \sum_{\alpha} D_{\alpha\alpha} = \Tr D $$

∎ This completes the proof. In short, we have merely written out carefully the “cyclicity of the trace, $\Tr(AB)=\Tr(BA)$.”

Why the trace? Why not some other quantity?

There are ways of extracting a number from a matrix other than the trace. The determinant $\det D(R)$ is also invariant under similarity transformations, and so is the set of eigenvalues. So why does group theory choose the trace?

The reason is additivity. When a representation is block-diagonalized and decomposed into a direct sum $D = D^{(1)}\oplus D^{(2)}$,

$$ \Tr D(R) = \Tr D^{(1)}(R) + \Tr D^{(2)}(R) $$

that is, $\chi(R)=\chi^{(1)}(R)+\chi^{(2)}(R)$ holds. The character is simply additive over direct sums. For the determinant, $\det D = \det D^{(1)}\cdot\det D^{(2)}$ becomes a product, and for the eigenvalues the result is a union of sets; in either case it is inconvenient to extract “how many of each are contained” with the tools of linear algebra (orthogonal projection).

Thanks to this additivity, the reduction $\chi = \sum_i a_i \chi^{(i)}$ of Section 8.8 turns into a system of simultaneous linear equations that can be solved just by taking inner products. This is why the character takes the leading role.

8.1.3 Elements of the same class have the same character

In Chapter 6 we divided the elements of a group into conjugacy classes. That $A$ and $B$ are conjugate meant that there exists some $X\in G$ such that $B = XAX^{-1}$.

Theorem 8.2 (Constancy of the character on a class)

If $A$ and $B$ belong to the same class, then in any representation

$$ \chi(A) = \chi(B) $$

That is, the character is a function of the class.

Proof

Let $B=XAX^{-1}$. Since $D$ is a representation, it preserves the multiplicative structure of the group:

$$ D(B) = D\!\left(XAX^{-1}\right) = D(X)\,D(A)\,D(X^{-1}) = D(X)\,D(A)\,D(X)^{-1} $$

In the last equality we used the property of representations $D(X^{-1})=D(X)^{-1}$ (this follows from $D(X)D(X^{-1})=D(XX^{-1})=D(E)=I$).

Now, setting $U \equiv D(X)^{-1}$, we have $D(B) = U^{-1}D(A)U$, which is in the form of a similarity transformation. By Theorem 8.1,

$$ \chi(B) = \Tr D(B) = \Tr\left(U^{-1}D(A)U\right) = \Tr D(A) = \chi(A) $$

∎

Physical Meaning: How much the information is compressed

An $\ell$-dimensional representation of a group of order $h$ consists of $h$ matrices of size $\ell\times\ell$, that is, $h\ell^2$ numbers. For the two-dimensional irreducible representation of $C_{3v}$ this is $6\times4=24$ numbers.

Taking characters, however, first reduces this to $h$ numbers ($6$ numbers), and since the value is the same within each class, the number of independent numbers is just the number of classes (three for $C_{3v}$). From $24 \to 3$, a reduction by a factor of eight.

Remarkably, almost nothing is lost in this compression. The second orthogonality relation (Section 8.4) shows that two elements whose characters coincide in all irreducible representations necessarily belong to the same class. The character table fully retains the “class structure” of the group.

Example 8.1: Computing the characters of the three-dimensional representation of $C_{3v}$ explicitly

Represent the six operations of $C_{3v}$ by $3\times3$ matrices with $(x,y,z)$ as the basis, and find their characters. Take the principal axis to be the $z$ axis and the mirror plane $\sigma_1$ to be the $yz$ plane ($x\to-x$).

Solution. We begin with the rotations. Setting $\phi=120^\circ$ in the formula of Chapter 4 (the rotation matrix about the $z$ axis), we obtain

$$ D(C_3)=\begin{pmatrix}-\tfrac12 & -\tfrac{\sqrt3}{2} & 0\\[2pt] \tfrac{\sqrt3}{2} & -\tfrac12 & 0\\[2pt] 0&0&1\end{pmatrix}, \qquad \chi(C_3) = -\tfrac12-\tfrac12+1 = 0 $$

For $C_3^2$ we have $\phi=240^\circ$, and since $\cos240^\circ=-\tfrac12$, the diagonal elements are the same. Hence $\chi(C_3^2)=0$. As predicted by Theorem 8.2, the two elements of the same class have the same character.

Next come the reflections. The reflection in a plane that contains the $z$ axis and is inclined at an angle $\theta$ from the $x$ axis is

$$ D(\sigma(\theta))=\begin{pmatrix}\cos2\theta & \sin2\theta & 0\\ \sin2\theta & -\cos2\theta & 0\\ 0&0&1\end{pmatrix} $$

(it is the reflection about the line $\theta$ within the $xy$ plane, with $z$ unchanged). Now let us take the trace:

$$ \chi(\sigma(\theta)) = \cos2\theta + (-\cos2\theta) + 1 = 1 $$

The $\theta$ has disappeared. In other words, whichever mirror plane we choose, the character is $1$. Written out explicitly, $\sigma_1$ corresponds to $\theta=90^\circ$, so that

$$ D(\sigma_1)=\begin{pmatrix}-1&0&0\\0&1&0\\0&0&1\end{pmatrix}, \qquad \sigma_2\ (\theta=30^\circ):\ \begin{pmatrix}\tfrac12&\tfrac{\sqrt3}{2}&0\\[2pt] \tfrac{\sqrt3}{2}&-\tfrac12&0\\[2pt] 0&0&1\end{pmatrix} $$

Although these are entirely different as matrices, both have trace $1$.

To summarize,

$$ \chi^{(xyz)} = \bigl(\chi(E),\,\chi(2C_3),\,\chi(3\sigma_v)\bigr) = (3,\,0,\,1) $$

∎ These three numbers represent the six $3\times3$ matrices (54 numerical values). In Section 8.8, we will decompose this $(3,0,1)$ into irreducible representations.

Supplement: How classes are written and the notation $N_k$

In the column headings of a character table, it is customary to write the number of elements in the class in front, as in $2C_3$ and $3\sigma_v$. $2C_3$ means “the class containing two operations of type $C_3$,” not “$C_3$ multiplied by 2.”

In this book we write this number as $N_k$. For $C_{3v}$, $N_1=1$ ($E$), $N_2=2$ ($2C_3$), and $N_3=3$ ($3\sigma_v$), so that $N_1+N_2+N_3=6=h$. In general,

$$ \sum_{k=1}^{n_c} N_k = h $$

holds ($n_c$ is the number of classes), because the classes cover the group without overlap. This $N_k$ appears as a “weight” in all of the orthogonality relations below. Forgetting $N_k$ is the most common mistake in character calculations.

8.2 The First Orthogonality Relation of Characters

8.2.1 Two lines from the great orthogonality theorem

Let us simply copy down the great orthogonality theorem proved in Chapter 7. Let $\Gamma^{(i)}$ and $\Gamma^{(j)}$ be irreducible unitary representations, $\ell_i$ the dimension of the former, and $h$ the order of the group. Then

$$ \begin{equation} \sum_{R\in G} D^{(i)}(R)^{*}_{\mu\nu}\, D^{(j)}(R)_{\alpha\beta} = \frac{h}{\ell_i}\,\delta_{ij}\,\delta_{\mu\alpha}\,\delta_{\nu\beta} \label{eq:8-got} \end{equation} $$

This was the statement that “the matrix elements are mutually orthogonal within an $h$-dimensional vector space.” Since a character is the sum of the diagonal elements, it suffices to set $\nu=\mu$ and $\beta=\alpha$ in Eq. \eqref{eq:8-got} and sum up.

Derivation: The first orthogonality relation

In Eq. \eqref{eq:8-got}, first set $\nu = \mu$ and $\beta = \alpha$.

$$ \sum_{R} D^{(i)}(R)^{*}_{\mu\mu}\, D^{(j)}(R)_{\alpha\alpha} = \frac{h}{\ell_i}\,\delta_{ij}\,\delta_{\mu\alpha}\,\delta_{\mu\alpha} $$

On the right-hand side, $\delta_{\mu\alpha}\delta_{\mu\alpha}$ equals $\delta_{\mu\alpha}$, because $\delta$ takes only the values $0$ and $1$. Next, sum both sides over $\mu=1,\dots,\ell_i$ and $\alpha=1,\dots,\ell_j$.

Left-hand side: If we interchange the order of summation, the sum over $\mu$ and the sum over $\alpha$ can be carried out independently:

$$ \sum_{R}\left[\sum_{\mu} D^{(i)}(R)^{*}_{\mu\mu}\right]\left[\sum_{\alpha} D^{(j)}(R)_{\alpha\alpha}\right] = \sum_{R} \chi^{(i)}(R)^{*}\,\chi^{(j)}(R) $$

This is precisely a sum of products of characters.

Right-hand side:

$$ \frac{h}{\ell_i}\delta_{ij}\sum_{\mu=1}^{\ell_i}\sum_{\alpha=1}^{\ell_j}\delta_{\mu\alpha} $$

Because of the factor $\delta_{ij}$, the whole expression vanishes for $i\ne j$. We need only consider $i=j$, in which case $\ell_i=\ell_j$, and the double sum $\sum_\mu\sum_\alpha \delta_{\mu\alpha}$ is “the number of pairs with $\mu=\alpha$,” that is, $\ell_i$. Therefore

$$ \frac{h}{\ell_i}\,\delta_{ij}\cdot \ell_i = h\,\delta_{ij} $$

Putting everything together,

$$ \begin{equation} \sum_{R\in G} \chi^{(i)}(R)^{*}\,\chi^{(j)}(R) = h\,\delta_{ij} \label{eq:8-orth1-R} \end{equation} $$

∎ Note that the troublesome factor $1/\ell_i$ in the great orthogonality theorem has been canceled exactly and has disappeared. The orthogonality relation of characters has the right-hand side $h$ regardless of the dimension. This is the source of the usefulness of characters.

8.2.2 The form grouped by classes

Eq. \eqref{eq:8-orth1-R} is a sum over all elements $R$ of the group, but since a character is constant on each class (Theorem 8.2), the sum can be grouped by classes.

Derivation: Grouping by classes

Divide the group $G$ into classes $C_1, C_2, \dots, C_{n_c}$. The classes do not overlap, and together they make up $G$, so for any function $f$,

$$ \sum_{R\in G} f(R) = \sum_{k=1}^{n_c} \sum_{R\in C_k} f(R) $$

Now $f(R)=\chi^{(i)}(R)^*\chi^{(j)}(R)$ is constant within the class $C_k$, and we write its value as $\chi^{(i)}(C_k)^*\chi^{(j)}(C_k)$. Since we are merely adding a constant $N_k$ times,

$$ \sum_{R\in C_k} f(R) = N_k\,\chi^{(i)}(C_k)^{*}\chi^{(j)}(C_k) $$

Therefore

$$ \begin{equation} \sum_{k=1}^{n_c} N_k\, \chi^{(i)}(C_k)^{*}\,\chi^{(j)}(C_k) = h\,\delta_{ij} \label{eq:8-orth1} \end{equation} $$

∎ This is the first orthogonality relation. It states the orthogonality between “rows” of the character table.

Physical Meaning: The rows of a character table are orthonormal vectors

Let us reread Eq. \eqref{eq:8-orth1} in the language of inner products. Define the $n_c$-dimensional complex vector

$$ \bm{v}^{(i)} \equiv \left(\sqrt{\frac{N_1}{h}}\,\chi^{(i)}(C_1),\ \sqrt{\frac{N_2}{h}}\,\chi^{(i)}(C_2),\ \dots,\ \sqrt{\frac{N_{n_c}}{h}}\,\chi^{(i)}(C_{n_c})\right) $$

Then Eq. \eqref{eq:8-orth1} can be written directly as

$$ \bm{v}^{(i)*}\cdot\bm{v}^{(j)} = \delta_{ij} $$

That is, when each row of the character table is viewed with the weight $\sqrt{N_k/h}$, it is an orthonormal vector in the $n_c$-dimensional space.

In an $n_c$-dimensional space, at most $n_c$ mutually orthogonal vectors can be chosen. From this simple fact, it follows immediately that the number $n_r$ of irreducible representations satisfies

$$ n_r \le n_c $$

In the next section we will also show the reverse inequality $n_r \ge n_c$ and establish the equality.

Example 8.2: Criterion for irreducibility

Given the character $\chi$ of a representation, derive a condition for determining whether it is irreducible.

Solution. Any representation can be decomposed into a direct sum of irreducible representations by block diagonalization, and characters are additive (see the “Why” box in Section 8.1.2), so we can write

$$ \chi(R) = \sum_i a_i \chi^{(i)}(R), \qquad a_i \in \{0,1,2,\dots\} $$

Here $a_i$ is a nonnegative integer that tells how many times $\Gamma^{(i)}$ appears. We now compute $\sum_R |\chi(R)|^2$.

$$ \sum_R \chi(R)^*\chi(R) = \sum_R \left(\sum_i a_i \chi^{(i)}(R)\right)^{*}\left(\sum_j a_j \chi^{(j)}(R)\right) $$

Since $a_i$ is a real number (a nonnegative integer), taking the complex conjugate does not change it. Interchanging the sums, we obtain

$$ = \sum_i\sum_j a_i a_j \underbrace{\sum_R \chi^{(i)}(R)^*\chi^{(j)}(R)}_{= h\delta_{ij}} = h\sum_i a_i^2 $$

Therefore

$$ \begin{equation} \frac{1}{h}\sum_{k} N_k \abs{\chi(C_k)}^2 = \sum_i a_i^2 \label{eq:8-irrtest} \end{equation} $$

The right-hand side is a sum of squares of nonnegative integers. It equals $1$ if and only if $a_i=1$ for exactly one $i$ and all the others are $0$. That is,

$\dfrac{1}{h}\sum_k N_k\abs{\chi(C_k)}^2 = 1 \iff$ the representation is irreducible

If the value is $2$, the only possibility is $1^2+1^2$, so the representation is “a sum of two distinct irreducible representations”; if $3$, a sum of three distinct ones; if $4$, it is either “$2^2$ (the same one twice)” or “$1^2\times4$.” ∎

Check: Trying this with $\chi^{(xyz)}=(3,0,1)$ of Example 8.1, we get $\frac{1}{6}\left[1\cdot9 + 2\cdot0 + 3\cdot1\right] = \frac{12}{6}=2$. Hence this is a sum of two distinct irreducible representations. In Section 8.8 we will find that it is $A_1\oplus E$.

8.3 Number of Irreducible Representations = Number of Classes

In the previous section we obtained $n_r \le n_c$ (the number of irreducible representations $\le$ the number of classes). In this section we prove the inequality in the opposite direction. As our tool we introduce the regular representation. This is a somewhat brash but powerful idea: make the group itself into a basis of a vector space.

8.3.1 The regular representation

Definition: Regular representation

To each element of a group $G=\{R_1,R_2,\dots,R_h\}$ of order $h$, assign an abstract vector $\ket{R_1},\dots,\ket{R_h}$, and consider the $h$-dimensional vector space having these as its basis. Define the action of a group element $X$ by

$$ D^{\mathrm{reg}}(X)\ket{R} = \ket{XR} $$

This is called the regular representation of $G$.

Derivation: The character of the regular representation is $(h,0,0,\dots,0)$

(1) It is a representation. $D^{\mathrm{reg}}(X)D^{\mathrm{reg}}(Y)\ket{R} = D^{\mathrm{reg}}(X)\ket{YR} = \ket{XYR} = D^{\mathrm{reg}}(XY)\ket{R}$. Since this holds for every basis vector, $D^{\mathrm{reg}}(X)D^{\mathrm{reg}}(Y)=D^{\mathrm{reg}}(XY)$. The condition for a representation is satisfied.

Moreover, by the rearrangement theorem (Chapter 6), multiplying by $X$ merely rearranges the elements of the group, so $D^{\mathrm{reg}}(X)$ is a permutation matrix having exactly one $1$ in each row and each column.

(2) The character. The matrix elements are

$$ D^{\mathrm{reg}}(X)_{SR} = \begin{cases} 1 & (S = XR)\\ 0 & (\text{otherwise})\end{cases} $$

The diagonal elements correspond to $S=R$, so $D^{\mathrm{reg}}(X)_{RR}\ne0$ holds when $R = XR$. Multiplying both sides by $R^{-1}$ from the right gives $E = X$. That is,

  • For $X=E$: the diagonal element is $1$ for every $R$. $\chi^{\mathrm{reg}}(E)=h$.
  • For $X\ne E$: all the diagonal elements are $0$. $\chi^{\mathrm{reg}}(X)=0$.
$$ \begin{equation} \chi^{\mathrm{reg}}(X) = h\,\delta_{X,E} \label{eq:8-chireg} \end{equation} $$

∎

Example 8.3: Writing out the regular representation of $C_3=\{E,\,a,\,a^2\}$ ($a^3=E$)

Take the basis in the order $\ket{E},\ket{a},\ket{a^2}$.

$D^{\mathrm{reg}}(a)$ maps $\ket{E}\to\ket{a}$, $\ket{a}\to\ket{a^2}$, and $\ket{a^2}\to\ket{a^3}=\ket{E}$. Using the column-vector convention (the first column is the destination of $\ket{E}$), we write

$$ D^{\mathrm{reg}}(E)=\begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix},\quad D^{\mathrm{reg}}(a)=\begin{pmatrix}0&0&1\\1&0&0\\0&1&0\end{pmatrix},\quad D^{\mathrm{reg}}(a^2)=\begin{pmatrix}0&1&0\\0&0&1\\1&0&0\end{pmatrix} $$

The traces are $3,\,0,\,0$, respectively, in agreement with Eq. \eqref{eq:8-chireg}. ∎

Since $C_3$ is an abelian group, it has three classes (each element forms a class by itself) and three irreducible representations, all one-dimensional $(1+1+1=3=h)$. Using $\omega=e^{2\pi i/3}$, the characters are $(1,1,1)$, $(1,\omega,\omega^2)$, and $(1,\omega^2,\omega)$. Indeed, the $3\times3$ regular representation decomposes into these three.

Derivation: $\sum_i \ell_i^2 = h$ emerges again from the decomposition of the regular representation

We find the number $a_i$ of times $\Gamma^{(i)}$ is contained in the regular representation using the reduction formula derived in Section 8.8 (this anticipates that section, but the derivation is independent).

$$ a_i = \frac{1}{h}\sum_{R} \chi^{(i)}(R)^{*}\,\chi^{\mathrm{reg}}(R) $$

By Eq. \eqref{eq:8-chireg}, the only term of the sum that survives is the one with $R=E$:

$$ a_i = \frac{1}{h}\,\chi^{(i)}(E)^{*}\cdot h = \chi^{(i)}(E) = \ell_i $$

That is, the regular representation contains the $i$th irreducible representation exactly $\ell_i$ times: a one-dimensional representation once, a two-dimensional representation twice, a three-dimensional representation three times, and so on.

Now we count dimensions. The dimension of the regular representation is $h$, and it is the sum of the dimensions of the irreducible representations it contains, so

$$ h = \sum_i a_i\,\ell_i = \sum_i \ell_i \cdot \ell_i $$
$$ \begin{equation} \sum_{i} \ell_i^2 = h \label{eq:8-dimsum} \end{equation} $$

∎ The relation that we showed from the great orthogonality theorem in Chapter 7 has appeared once more, this time by way of the regular representation. This relation is the key to fixing the dimensions when we construct a character table.

We can also confirm the same thing in terms of characters. We have $\chi^{\mathrm{reg}}(E)=\sum_i a_i \chi^{(i)}(E)=\sum_i \ell_i^2$, and this equals $h$. For $X\ne E$ we obtain $\sum_i \ell_i \chi^{(i)}(X)=0$, which is a special case of the second orthogonality relation derived in Section 8.4.

8.3.2 The space of class functions, and characters as its basis

Definition: Class function

A complex-valued function $f: G\to\mathbb{C}$ on a group $G$ that takes the same value on elements of the same class, that is, one that satisfies, for any $A,X\in G$,

$$ f(XAX^{-1}) = f(A) $$

is called a class function. By Theorem 8.2, the character of any representation is a class function.

The set of all class functions forms a complex vector space (since both sums and scalar multiples of class functions are class functions). What is its dimension? Consider the function $\theta_k$ that equals $1$ only on the class $C_k$ and $0$ elsewhere. These are obviously linearly independent, and any class function $f$ can be written uniquely as $f=\sum_k f(C_k)\theta_k$. Therefore

$$ \dim(\text{space of class functions}) = n_c $$

holds. In this space live the $n_r$ characters $\chi^{(1)},\dots,\chi^{(n_r)}$, which are mutually orthogonal (and hence linearly independent) by the first orthogonality relation. What remains is to show that they span the whole space.

Theorem 8.3 (Number of irreducible representations = number of classes)

$$ n_r = n_c $$

That is, the number of irreducible representations of a finite group is exactly equal to the number of conjugacy classes.

Proof: The only class function orthogonal to the characters is zero

Let $f$ be a class function that is orthogonal to the characters of all the irreducible representations:

$$ \sum_{R\in G} f(R)^{*}\,\chi^{(i)}(R) = 0 \qquad (\text{for all } i) \tag{*} $$

If we can derive $f\equiv0$ from this, then the orthogonal complement of the subspace spanned by the characters is zero, which means that the characters span the whole space.

Step 1: Construct the matrix $T^{(i)}$. For each irreducible representation $\Gamma^{(i)}$, define the $\ell_i\times\ell_i$ matrix

$$ T^{(i)} \equiv \sum_{R\in G} f(R)^{*}\, D^{(i)}(R) $$

.

Step 2: Show that $T^{(i)}$ commutes with every $D^{(i)}(X)$. We compute $D^{(i)}(X)^{-1}T^{(i)}D^{(i)}(X)$.

$$ D^{(i)}(X)^{-1}\,T^{(i)}\,D^{(i)}(X) = \sum_{R} f(R)^{*}\, D^{(i)}(X)^{-1}D^{(i)}(R)D^{(i)}(X) = \sum_{R} f(R)^{*}\, D^{(i)}(X^{-1}RX) $$

Now change the variable to $R' = X^{-1}RX$. As $R$ runs over the whole group, so does $R'$ (rearrangement theorem), so the range of the sum does not change. Since $R = XR'X^{-1}$,

$$ = \sum_{R'} f(XR'X^{-1})^{*}\, D^{(i)}(R') $$

Because $f$ is a class function, $f(XR'X^{-1}) = f(R')$. Hence

$$ = \sum_{R'} f(R')^{*}\,D^{(i)}(R') = T^{(i)} $$

Multiplying both sides by $D^{(i)}(X)$ from the left gives $T^{(i)}D^{(i)}(X) = D^{(i)}(X)T^{(i)}$. They commute.

Step 3: Use Schur's first lemma. Since $\Gamma^{(i)}$ is irreducible and $T^{(i)}$ commutes with all of its representation matrices, we must have $T^{(i)} = \lambda_i I$ (a constant multiple of the identity matrix). The constant $\lambda_i$ is determined from the trace:

$$ \Tr T^{(i)} = \lambda_i \ell_i, \qquad \Tr T^{(i)} = \sum_R f(R)^{*}\,\Tr D^{(i)}(R) = \sum_R f(R)^{*}\chi^{(i)}(R) \overset{(*)}{=} 0 $$

Therefore $\lambda_i = 0$, that is,

$$ T^{(i)} = \sum_R f(R)^{*} D^{(i)}(R) = 0 \qquad(\text{for all } i) $$

Step 4: Extend to an arbitrary representation. Any representation $D$ can be block-diagonalized into a direct sum of irreducible representations by a suitable similarity transformation (Chapter 7). That is, $U^{-1}D(R)U = \bigoplus_i D^{(i)}(R)$ (the same irreducible representation may appear several times). Therefore

$$ U^{-1}\left[\sum_R f(R)^{*}D(R)\right]U = \bigoplus_i \sum_R f(R)^{*}D^{(i)}(R) = \bigoplus_i 0 = 0 $$

Since $U$ is invertible, $\sum_R f(R)^{*}D(R)=0$. For any representation whatsoever, this sum is the zero matrix.

Step 5: Apply it to the regular representation to finish the proof. Let $D=D^{\mathrm{reg}}$, and let this zero matrix act on the basis vector $\ket{E}$.

$$ 0 = \left[\sum_R f(R)^{*}D^{\mathrm{reg}}(R)\right]\ket{E} = \sum_R f(R)^{*}\ket{RE} = \sum_R f(R)^{*}\ket{R} $$

But $\{\ket{R}\}_{R\in G}$ is a linearly independent basis. A linear combination of basis vectors is the zero vector only when all the coefficients are zero. Hence

$$ f(R)^{*} = 0 \quad(\text{for all } R) \quad\Longrightarrow\quad f \equiv 0 $$

∎ This shows that the characters span the space of class functions $(n_c$-dimensional$)$. Since $n_r$ linearly independent vectors span an $n_c$-dimensional space, $n_r = n_c$. (We had already obtained $n_r\le n_c$ in Section 8.2.)

Supplement: An alternative approach using class multiplication

The textbook by Dresselhaus takes an argument that uses the class multiplication coefficients. We only outline the idea. It is also useful later for studying the structure of the classes.

Consider the “class sum,” the sum of all the elements belonging to the class $C_k$:

$$ \mathcal{C}_k \equiv \sum_{R\in C_k} R $$

(this is a quantity obtained by formally adding group elements, and is an element of the group algebra). For any $X\in G$ we have $X\mathcal{C}_kX^{-1}=\mathcal{C}_k$ (since conjugation merely rearranges the contents of a class). That is, $\mathcal{C}_k$ commutes with all the elements.

The product $\mathcal{C}_k\mathcal{C}_l$ of two commuting quantities also commutes with all the elements, so it should be expressible as a linear combination of class sums:

$$ \begin{equation} \mathcal{C}_k\,\mathcal{C}_l = \sum_{m} c_{klm}\,\mathcal{C}_m \label{eq:8-classmult} \end{equation} $$

The $c_{klm}$ are nonnegative integers and are called the class multiplication coefficients. Mapping by the representation $\Gamma^{(i)}$, $D^{(i)}(\mathcal{C}_k)\equiv\sum_{R\in C_k}D^{(i)}(R)$ commutes with all the $D^{(i)}(X)$, so by Schur's first lemma it is a constant multiple of the identity matrix:

$$ D^{(i)}(\mathcal{C}_k) = \lambda_k^{(i)} I, \qquad \text{taking the trace}\quad N_k\chi^{(i)}(C_k) = \lambda_k^{(i)}\,\ell_i $$ $$ \therefore\quad \lambda_k^{(i)} = \frac{N_k\,\chi^{(i)}(C_k)}{\ell_i} $$

Mapping Eq. \eqref{eq:8-classmult} by the representation gives $\lambda_k^{(i)}\lambda_l^{(i)} = \sum_m c_{klm}\lambda_m^{(i)}$, that is,

$$ N_kN_l\,\chi^{(i)}(C_k)\chi^{(i)}(C_l) = \ell_i\sum_m c_{klm}N_m\chi^{(i)}(C_m) $$

This relation can be regarded as simultaneous equations for the $n_c$ unknowns $\lambda_k$, and since the number of independent solutions is exactly $n_c$, it follows that $n_r=n_c$.

Example 8.4: Computing class products explicitly in $C_{3v}$

For $\mathcal{C}_1=E$, $\mathcal{C}_2=C_3+C_3^2$, and $\mathcal{C}_3=\sigma_1+\sigma_2+\sigma_3$, find $\mathcal{C}_2\mathcal{C}_2$ and $\mathcal{C}_3\mathcal{C}_3$, and check them with the $E$ representation and the $A_2$ representation.

Solution. First, $\mathcal{C}_2\mathcal{C}_2$. Expanding and using $C_3^3=E$, we get

$$ (C_3+C_3^2)(C_3+C_3^2) = C_3^2 + C_3^3 + C_3^3 + C_3^4 = C_3^2 + E + E + C_3 = 2E + (C_3+C_3^2) $$ $$ \therefore\quad \mathcal{C}_2\mathcal{C}_2 = 2\mathcal{C}_1 + \mathcal{C}_2 \qquad (c_{221}=2,\ c_{222}=1,\ c_{223}=0) $$

Next, $\mathcal{C}_3\mathcal{C}_3$. There are three terms with $\sigma_i^2=E$, and $3\times2=6$ terms with products $\sigma_i\sigma_j$ for $i\ne j$. The product of two reflections is a rotation, so the six terms consist of three $C_3$ and three $C_3^2$. Hence

$$ \mathcal{C}_3\mathcal{C}_3 = 3E + 3(C_3+C_3^2) = 3\mathcal{C}_1 + 3\mathcal{C}_2 \qquad (c_{331}=3,\ c_{332}=3,\ c_{333}=0) $$

Check 1 (two-dimensional representation $E$, $\ell=2$, character $(2,-1,0)$).

$$ \lambda_1 = \frac{1\cdot2}{2}=1,\qquad \lambda_2 = \frac{2\cdot(-1)}{2}=-1,\qquad \lambda_3 = \frac{3\cdot0}{2}=0 $$

$\mathcal{C}_2\mathcal{C}_2 = 2\mathcal{C}_1+\mathcal{C}_2$ means $\lambda_2^2 = 2\lambda_1+\lambda_2$. The left-hand side is $(-1)^2=1$ and the right-hand side is $2(1)+(-1)=1$. They agree ✓

$\mathcal{C}_3\mathcal{C}_3=3\mathcal{C}_1+3\mathcal{C}_2$ means $\lambda_3^2=3\lambda_1+3\lambda_2$. The left-hand side is $0$ and the right-hand side is $3(1)+3(-1)=0$. They agree ✓

Check 2 (one-dimensional representation $A_2$, character $(1,1,-1)$).

$$ \lambda_1 = 1,\qquad \lambda_2 = \frac{2\cdot1}{1}=2,\qquad \lambda_3=\frac{3\cdot(-1)}{1}=-3 $$

$\lambda_3^2 = 9$ and $3\lambda_1+3\lambda_2 = 3+6=9$. They agree ✓ ∎

8.4 The Second Orthogonality Relation — Orthogonality of Columns

By Theorem 8.3, the character table is square: the number of rows (the number of irreducible representations) and the number of columns (the number of classes) are both equal to $n\equiv n_r=n_c$. For a square matrix, “the rows are orthonormal” implies “the columns are orthonormal” — this is the essence of the second orthogonality relation.

Derivation: The second orthogonality relation

Define an $n\times n$ matrix $U$ by its components

$$ U_{ik} \equiv \sqrt{\frac{N_k}{h}}\;\chi^{(i)}(C_k) $$

($i$ labels the row = irreducible representation, and $k$ labels the column = class). The first orthogonality relation \eqref{eq:8-orth1} can be written as

$$ \sum_{k=1}^{n} U_{ik}^{*}\,U_{jk} = \frac{1}{h}\sum_k N_k \chi^{(i)}(C_k)^*\chi^{(j)}(C_k) = \delta_{ij} $$

Since $(U^\dagger)_{ki}=U_{ik}^{*}$, the left-hand side is $\sum_k U_{jk}(U^\dagger)_{ki}=(UU^\dagger)_{ji}$ (note the order of the indices: the $(i,j)$ component of $UU^\dagger$ is $\sum_k U_{ik}U_{jk}^{*}$, in which the complex conjugate sits on the other factor). The $\delta_{ij}$ on the right-hand side equals $\delta_{ji}$, so in the end

$$ U U^{\dagger} = I $$

Here the squareness matters. If $UU^\dagger = I$ for a square matrix, then $U^\dagger$ is a right inverse of $U$, and the right inverse of a square matrix is also a left inverse ($\det U \cdot \det U^\dagger = 1 \ne 0$ shows that $U$ is invertible, and $U^{-1}=U^{\dagger}$). Therefore

$$ U^{\dagger}U = I $$

also holds. In components, $(U^\dagger U)_{kk'} = \sum_i (U^\dagger)_{ki}U_{ik'} = \sum_i U_{ik}^{*}U_{ik'}$, so

$$ \sum_{i=1}^{n} \sqrt{\frac{N_k}{h}}\,\chi^{(i)}(C_k)^{*}\;\sqrt{\frac{N_{k'}}{h}}\,\chi^{(i)}(C_{k'}) = \delta_{kk'} $$

Multiply both sides by $h/\sqrt{N_kN_{k'}}$. For $k\ne k'$ both sides are $0$, and for $k=k'$ the right-hand side becomes $h/N_k$, so

$$ \begin{equation} \sum_{i} \chi^{(i)}(C_k)^{*}\,\chi^{(i)}(C_{k'}) = \frac{h}{N_k}\,\delta_{kk'} \label{eq:8-orth2} \end{equation} $$

∎ Note that, unlike in the first orthogonality relation, the sum here is taken without the weight $N_k$; $N_k$ appears on the right-hand side.

Why? Setting $k'=1$ (the column of the identity element) gives a handy check formula

Number the classes so that $C_1=\{E\}$ (hence $N_1=1$ and $\chi^{(i)}(C_1)=\ell_i$). Setting $k'=1$ in Eq. \eqref{eq:8-orth2} gives

$$ \begin{equation} \sum_{i} \ell_i\,\chi^{(i)}(C_k) = h\,\delta_{k1} \label{eq:8-colcheck} \end{equation} $$

($\chi^{(i)}(C_1)=\ell_i$ is real, so no complex conjugate is needed.) That is,

  • for $k=1$: $\sum_i \ell_i^2 = h$ — the dimension theorem \eqref{eq:8-dimsum} reappears.
  • for $k\ne1$: $\sum_i \ell_i\,\chi^{(i)}(C_k)=0$ — if each column is weighted by the first column (the dimensions) and summed, the result is zero.

This is very handy for checking a character table. Checking against the table of $C_{3v}$: the column of $2C_3$ gives $1\cdot1+1\cdot1+2\cdot(-1)=0$ ✓, and the column of $3\sigma_v$ gives $1\cdot1+1\cdot(-1)+2\cdot0=0$ ✓.

Physical Meaning: The character table distinguishes the classes completely

Setting $k=k'$ in Eq. \eqref{eq:8-orth2} gives

$$ \sum_i \abs{\chi^{(i)}(C_k)}^2 = \frac{h}{N_k} $$

This says that “the squared length of the $k$th column” is $h/N_k$. The left-hand side is never zero (at the very least, the identity representation contributes $1$), so no column is a zero vector.

Moreover, columns with $k\ne k'$ are orthogonal. Hence two classes can never have the same character in every irreducible representation. Conversely, if for elements $A$ and $B$ of the group “$\chi^{(i)}(A)=\chi^{(i)}(B)$ for all $i$” holds, then $A$ and $B$ necessarily belong to the same class. The character table records the class structure of the group completely.

Physically, this means that “the number of quantum states distinguishable by symmetry equals the number of rows of the character table, and the number of distinguishable symmetry operations equals the number of columns.” The discussion of selection rules in Chapter 10 is built entirely on this.

8.5 Example: Constructing the Character Table of $C_{3v}$ from Scratch

Now we come to the centerpiece of this chapter. We construct the character table of $C_{3v}$ (the symmetry of an equilateral triangle, and the point group of the ammonia molecule $\mathrm{NH_3}$) without looking anything up. We use only the three tools proved so far:

  1. the number of irreducible representations = the number of classes (Theorem 8.3)
  2. $\sum_i \ell_i^2 = h$ (Eq. \eqref{eq:8-dimsum})
  3. the first orthogonality relation (Eq. \eqref{eq:8-orth1})

8.5.1 Steps ① and ②: Write out the elements and divide them into classes

The elements of $C_{3v}$ are the six operations: the identity operation $E$, the rotations $C_3$ ($120^\circ$) and $C_3^2$ ($240^\circ$) about the principal axis, and the reflections $\sigma_1,\sigma_2,\sigma_3$ in the three mirror planes containing the principal axis.

$$ C_{3v} = \{E,\ C_3,\ C_3^2,\ \sigma_1,\ \sigma_2,\ \sigma_3\},\qquad h = 6 $$

The classification into classes was carried out in Chapter 6 (Figure 8.1). Restating only the result,

$$ C_1=\{E\}\ (N_1=1),\qquad C_2=\{C_3,C_3^2\}\ (N_2=2),\qquad C_3=\{\sigma_1,\sigma_2,\sigma_3\}\ (N_3=3) $$

Just to be safe, let us verify only that $C_3$ and $C_3^2$ are conjugate. Consider $\sigma_1 C_3 \sigma_1^{-1}$. A reflection reverses the sense of rotation, so $\sigma_1 C_3 \sigma_1 = C_3^{-1} = C_3^2$. They are indeed conjugate. Similarly, from $C_3\sigma_1 C_3^{-1}=\sigma_2$ and so on, the three reflections form a single class.

The number of classes is $n_c = 3$.

8.5.2 Step ③: Determine the dimensions

By Theorem 8.3, the number of irreducible representations is also $n_r = 3$. Let their dimensions be $\ell_1,\ell_2,\ell_3$ (positive integers). Then Eq. \eqref{eq:8-dimsum} gives

$$ \ell_1^2 + \ell_2^2 + \ell_3^2 = 6 $$

We search exhaustively for combinations of three positive integers whose squares sum to $6$.

That is, $C_{3v}$ has two one-dimensional irreducible representations and one two-dimensional irreducible representation. The first column of the character table is thus fixed, from the top, as $1,1,2$.

Step ④: The identity representation is always present

Every group has the representation $D(R)=1$, which assigns the number $1$ to every element. The group product is preserved because $1\times1=1$, so this is indeed a representation. It is called the identity representation, or totally symmetric representation, and it is one-dimensional and irreducible (a one-dimensional representation cannot be decomposed into blocks, so it is always irreducible). All its characters are $1$:

$$ \chi^{(1)}(C_k) = 1 \quad(\text{all } k) $$

By convention, it is written in the first row of the character table, and in $C_{3v}$ it is named $A_1$ (the meaning of the symbols is explained in Section 8.9).

Dividing both sides by $3$,

$$ 5c^2 + 2c - 3 = 0 \quad\Longrightarrow\quad (5c-3)(c+1) = 0 \quad\Longrightarrow\quad c = \frac{3}{5}\ \ \text{or}\ \ c = -1 $$

Which one to take. Here we use a property of one-dimensional representations. In a one-dimensional representation the matrices are $1\times1$, that is, the numbers themselves, and $\chi(R)=D(R)$. Therefore $D(R^n)=D(R)^n$ gives $\chi(R^n)=\chi(R)^n$. Since $\sigma_v^2=E$,

$$ \chi(\sigma_v)^2 = \chi(E) = 1 \quad\Longrightarrow\quad c = \pm1 $$

$c=3/5$ does not satisfy this condition and is rejected. Hence $c=-1$. Returning to (i),

$$ 1 + 2b + 3(-1) = 0 \quad\Longrightarrow\quad 2b = 2 \quad\Longrightarrow\quad b = 1 $$

(We also confirm the validity of $b$. From $C_3^3=E$ we have $b^3=1$, and since $C_3$ and $C_3^2=C_3^{-1}$ belong to the same class, $b = \chi(C_3^{-1}) = b^{-1}$, that is, $b^2=1$. The only value satisfying both $b^3=1$ and $b^2=1$ is $b=1$. This is consistent.)

Example 8.6: Checking the $E$ representation with actual $2\times2$ matrices

The character table says only that “the characters of the two-dimensional representation are $(2,-1,0)$.” Check that such a two-dimensional representation really exists, taking the vector $(x,y)$ in the $xy$ plane as the basis.

Solution. Extracting only the $xy$ components of the rotation by $\phi$ about the $z$ axis, we obtain

$$ D^{(E)}(C_3) = \begin{pmatrix}\cos120^\circ & -\sin120^\circ\\ \sin120^\circ & \cos120^\circ\end{pmatrix} = \begin{pmatrix}-\tfrac12 & -\tfrac{\sqrt3}{2}\\[3pt] \tfrac{\sqrt3}{2} & -\tfrac12\end{pmatrix} $$ $$ \Tr = -\tfrac12 - \tfrac12 = -1 \quad\checkmark $$

The $xy$ components of the reflection $\sigma_1$ (the $yz$ plane, $x\to-x$) are

$$ D^{(E)}(\sigma_1) = \begin{pmatrix}-1 & 0\\ 0 & 1\end{pmatrix}, \qquad \Tr = -1+1 = 0 \quad\checkmark $$

The identity operation is the $2\times2$ identity matrix, with $\Tr=2$ ✓. The characters $(2,-1,0)$ have been reproduced.

Check of irreducibility. If this two-dimensional representation were reducible, it could be decomposed into a sum of two one-dimensional representations. However, $D^{(E)}(C_3)$ and $D^{(E)}(\sigma_1)$ do not commute:

$$ D(C_3)D(\sigma_1) = \begin{pmatrix}\tfrac12 & -\tfrac{\sqrt3}{2}\\[3pt] -\tfrac{\sqrt3}{2} & -\tfrac12\end{pmatrix}, \qquad D(\sigma_1)D(C_3) = \begin{pmatrix}\tfrac12 & \tfrac{\sqrt3}{2}\\[3pt] \tfrac{\sqrt3}{2} & -\tfrac12\end{pmatrix} $$

Matrices that do not commute cannot be diagonalized simultaneously, so simultaneous block diagonalization (= decomposition into a direct sum of one-dimensional representations) is impossible. The representation is irreducible. Eq. \eqref{eq:8-irrtest} also gives $\frac16[1(4)+2(1)+3(0)]=1$, which again shows that it is irreducible. ∎

Caution: Why the character of $\sigma_v$ in the two-dimensional representation is $0$

You might think, “Since it is a reflection, shouldn’t it be $\pm1$?” But that holds only for one-dimensional representations. The two-dimensional reflection matrix $\mathrm{diag}(-1,1)$ inverts one axis and keeps the other, so its trace is $-1+1=0$.

In general, the character of an $n$-dimensional representation is a complex number satisfying $\abs{\chi}\le n$, and when it is real it can take any value from $-n$ to $n$ (we saw an example of complex characters for $C_3$ in Example 8.3). $\chi(R)$ is a rough estimate of “how many components the operation leaves unchanged,” not a quantity that carries only a sign. This viewpoint leads, in Section 8.8, to the convenient calculation method of “counting only the atoms that do not move.”

8.6 Example: Constructing the Character Table of $C_{4v}$ from Scratch

We repeat the same procedure for a group one step larger: $C_{4v}$ (the symmetry of a square, and the point group of the room-temperature phase $4mm$ of tetragonal perovskite $\mathrm{BaTiO_3}$).

8.6.1 Steps ①②: Elements and classes

$$ C_{4v} = \{E,\ C_4,\ C_4^3,\ C_2,\ \sigma_v,\ \sigma_v',\ \sigma_d,\ \sigma_d'\},\qquad h = 8 $$

Here $C_2 = C_4^2$. As shown in Figure 8.4, there are five classes:

$$ \{E\}\,(N=1),\quad \{C_4,C_4^3\}\,(N=2),\quad \{C_2\}\,(N=1),\quad \{\sigma_v,\sigma_v'\}\,(N=2),\quad \{\sigma_d,\sigma_d'\}\,(N=2) $$

The total is $1+2+1+2+2=8=h$ ✓. The reason $C_2$ forms a class by itself is that $C_2$ lies in the center of this group (it commutes with all elements).

8.6.2 Step ③: Dimensions

There are five irreducible representations. We look for a set of positive integers satisfying $\sum_{i=1}^{5}\ell_i^2 = 8$. Since $\ell_i\ge1$, the sum is at least $5$, so there is a margin of only $3$. Including one $\ell=2$ raises the sum by $4-1=3$, giving exactly $8$. Including an $\ell=3$ would raise it by $9-1=8$, giving $5+8=13$, which is too large. Therefore

$$ (\ell_1,\dots,\ell_5) = (1,1,1,1,2),\qquad 1+1+1+1+4 = 8\ \checkmark $$

There are four one-dimensional representations and one two-dimensional representation.

8.6.3 Steps ④⑤: The identity representation and the four one-dimensional representations

Derivation: One-dimensional representations are determined only by the signs of $C_4$ and $\sigma_v$

In a one-dimensional representation, $\chi(RS)=\chi(R)\chi(S)$ holds (because the matrices are just numbers). Using this, the number of independent unknowns is greatly reduced.

$$ \chi(C_4) = \chi(C_4^{-1}) = \chi(C_4)^{-1} \quad\Longrightarrow\quad \chi(C_4)^2 = 1 \quad\Longrightarrow\quad \chi(C_4) = \pm 1 $$

We therefore let $p\equiv\chi(C_4)=\pm1$.

(b) $\chi(C_2)$ is determined automatically. Since $C_2 = C_4^2$,

$$ \chi(C_2) = \chi(C_4)^2 = p^2 = 1 $$

In a one-dimensional representation the character of $C_2$ is always $+1$.

(c) Candidates for $\chi(\sigma_v)$. From $\sigma_v^2=E$ we have $\chi(\sigma_v)^2=1$, so $q\equiv\chi(\sigma_v)=\pm1$.

(d) $\chi(\sigma_d)$ is dependent. From the geometry of the square, a diagonal reflection is “an edge reflection rotated by $45^\circ$,” and can be written $\sigma_d = C_4\,\sigma_v$ (apply $\sigma_v$ and then rotate by $C_4$). Therefore

$$ \chi(\sigma_d) = \chi(C_4)\chi(\sigma_v) = pq $$

We let the fifth row be $(2,\,x,\,y,\,z,\,w)$ (with $\chi(E)=\ell=2$). We write down the orthogonality condition with each of the four one-dimensional representations. The weights are $(N_1,\dots,N_5)=(1,2,1,2,2)$.

(I) − (II): Only the terms in $z,w$ remain:

$$ 4z + 4w = 0 \quad\Longrightarrow\quad z = -w \tag{V} $$

(I) − (III): The terms in $x$ and $w$ remain:

$$ 4x + 4w = 0 \quad\Longrightarrow\quad x = -w \tag{VI} $$

(I) − (IV): The terms in $x$ and $z$ remain:

$$ 4x + 4z = 0 \quad\Longrightarrow\quad x = -z \tag{VII} $$

By (V), $z=-w$; substituting into (VII) gives $x = -z = w$. But (VI) says $x=-w$. For both to hold we need

$$ w = -w \quad\Longrightarrow\quad w = 0 $$

Therefore, by (V) and (VI), $z=0$ and $x=0$. Substituting these back into (I),

$$ 2 + 0 + y + 0 + 0 = 0 \quad\Longrightarrow\quad y = -2 $$

∎ The characters of the two-dimensional representation are

$$ E = (2,\ 0,\ -2,\ 0,\ 0) $$

$$ 1(2^2) + 2(0^2) + 1((-2)^2) + 2(0^2) + 2(0^2) = 4 + 0 + 4 + 0 + 0 = 8 = h \quad\checkmark $$

Why is the $C_2$ column so similar to the $E$ column?

Looking at Table 8.4, the $C_2$ column $(1,1,1,1,-2)$ differs from the $E$ column $(1,1,1,1,2)$ only in the sign of the entry for the two-dimensional representation. This is not a coincidence.

$C_2$ is a central element of $C_{4v}$ (it commutes with all elements). By Schur's first lemma, in an irreducible representation $\Gamma^{(i)}$ the matrix $D^{(i)}(C_2)$ must be a constant multiple of the identity matrix: $D^{(i)}(C_2) = \lambda_i I$. Since $C_2^2=E$, we have $\lambda_i^2=1$, that is, $\lambda_i=\pm1$. Therefore

$$ \chi^{(i)}(C_2) = \lambda_i\,\ell_i = \pm\ell_i $$

The absolute value of the character is necessarily equal to the dimension. For the one-dimensional representations $+1$ is chosen (as stated earlier), and for the two-dimensional representation $-2$ is chosen.

In general, the character of a central element always satisfies $\abs{\chi}=\ell$. The inversion $i$ of $O_h$ is also such an element; please check that $\chi(i)=\pm\ell$ in the table of the next section.

8.7.2 Constructing $O_h$ by a direct product

Definition: Direct product of groups

Let $G_1=\{A_1,\dots\}$ and $G_2=\{B_1,\dots\}$ be two groups whose only common element is the identity element and such that every $A_i$ commutes with every $B_j$ $(A_iB_j=B_jA_i)$. Then the set of products

$$ G_1\otimes G_2 \equiv \{A_iB_j\} $$

is a group. It is called the direct-product group, and its order is $h_1h_2$.

The inversion operation $i$ is the operation $\rr\to-\rr$, which “reverses only the orientation,” so it commutes with every rotation and reflection. Also, since $i^2=E$, the set $\{E,i\}$ forms a group of order 2 ($C_i$). Because $O$ contains no operation with $\det=-1$, the only common element of $O$ and $\{E,i\}$ is $E$. Hence

$$ \begin{equation} O_h = O \otimes \{E,\,i\},\qquad \abs{O_h} = 24\times2 = 48 \label{eq:8-Ohdp} \end{equation} $$

Derivation: The characters of a direct-product group multiply

From an irreducible representation $\Gamma^{(a)}$ of $G_1$ (dimension $\ell_a$, matrices $D^{(a)}$) and an irreducible representation $\Gamma^{(b)}$ of $G_2$ (dimension $\ell_b$), we construct a representation of the direct-product group by

$$ D^{(a\times b)}(A_iB_j) \equiv D^{(a)}(A_i)\otimes D^{(b)}(B_j) $$

(the Kronecker product, of dimension $\ell_a\ell_b$). As one sees by writing out the components, the trace of a Kronecker product is

$$ \Tr(M\otimes N) = \sum_{\mu\alpha}(M\otimes N)_{(\mu\alpha),(\mu\alpha)} = \sum_{\mu}M_{\mu\mu}\sum_{\alpha}N_{\alpha\alpha} = (\Tr M)(\Tr N) $$

Therefore

$$ \begin{equation} \chi^{(a\times b)}(A_iB_j) = \chi^{(a)}(A_i)\;\chi^{(b)}(B_j) \label{eq:8-dpchar} \end{equation} $$

First we show that the representation is irreducible. Every element of $G_1\otimes G_2$ can be written uniquely as $A_iB_j$ and the order is $h_1h_2$, so the left-hand side of the irreducibility criterion \eqref{eq:8-irrtest} factorizes into a product by Eq. \eqref{eq:8-dpchar}:

$$ \frac{1}{h_1h_2}\sum_{i,j}\bigl|\chi^{(a)}(A_i)\,\chi^{(b)}(B_j)\bigr|^2 = \left[\frac{1}{h_1}\sum_i\bigl|\chi^{(a)}(A_i)\bigr|^2\right] \left[\frac{1}{h_2}\sum_j\bigl|\chi^{(b)}(B_j)\bigr|^2\right] = 1\cdot 1 = 1 $$

Hence $D^{(a\times b)}$ is irreducible for every pair $(a,b)$. Since the characters $\chi^{(a)}\chi^{(b)}$ differ from pair to pair, these representations are also mutually inequivalent.

Next we confirm that the number of representations is correct. If $G_1$ has $n_1$ irreducible representations and $G_2$ has $n_2$, we obtain $n_1n_2$ irreducible representations in this way, and the sum of the squared dimensions is

$$ \sum_{a,b}(\ell_a\ell_b)^2 = \left(\sum_a\ell_a^2\right)\left(\sum_b\ell_b^2\right) = h_1h_2 $$

which equals the order of the direct-product group. This saturates Eq. \eqref{eq:8-dimsum}, so these are all of the irreducible representations. ∎

(Note the order of the argument. $\sum_i\ell_i^2=h$ is a theorem about irreducible representations, not a criterion for irreducibility. Irreducibility does not follow merely from the sum of the squared dimensions matching, so we must first confirm irreducibility with the criterion \eqref{eq:8-irrtest}.)

$C_i=\{E,i\}$ is an abelian group of order 2, and its irreducible representations are two one-dimensional representations.

$$ A_g = (1,\ 1)\ \ (\chi(i)=+1),\qquad A_u = (1,\ -1)\ \ (\chi(i)=-1) $$

Here $g$ is the initial of gerade (German for “even”) and $u$ is the initial of ungerade (“odd”). The irreducible representations of $O_h$ are therefore

$$ \{A_{1g},A_{2g},E_g,T_{1g},T_{2g}\} \cup \{A_{1u},A_{2u},E_u,T_{1u},T_{2u}\} $$

ten in all. By Eq. \eqref{eq:8-dpchar}, the characters are determined by the following rule.

$$ \begin{equation} \chi_g(R) = \chi_g(iR) = \chi^{O}(R), \qquad \chi_u(R) = \chi^{O}(R),\quad \chi_u(iR) = -\chi^{O}(R) \label{eq:8-gu} \end{equation} $$

Here, the remaining five classes of $O_h$ are the classes of $O$ multiplied by $i$. Using the relations between rotoinversions and rotoreflections from Chapter 4, we obtain

Physical Meaning: $g$/$u$ determines the selection rule

In a group with an inversion center such as $O_h$, every state is classified as either $g$ (even) or $u$ (odd). The $s$ and $d$ orbitals are $g$, and the $p$ and $f$ orbitals are $u$ (because the spherical harmonics $Y_{lm}$ are multiplied by $(-1)^l$ under inversion).

The electric dipole $\bm{r}=(x,y,z)$ is $T_{1u}$ in Table 8.7, that is, $u$. Therefore, for the matrix element $\bra{f}\bm{r}\ket{i}$ of a dipole transition not to vanish, when the three factors are arranged in the order (final state, operator $\bm{r}$, initial state), the middle one is always $u$, so the whole product must be $g$, as in $u\times u\times g$ or $g\times u\times u$. In other words, the initial and final states must have different parities—this is the Laporte rule.

This is why the $d$–$d$ transitions ($g\to g$) of transition-metal oxides are weak and their colors are pale. In Chapter 10, we develop this argument rigorously in the language of direct-product representations and reduction into irreducible representations.

8.8 The Reduction Formula

Now that we have the character table, it is finally time to use it. In an actual problem, we are first given a reducible representation whose basis is “some collection of degrees of freedom” (molecular displacements, a set of atomic orbitals, lattice vibrations, and so on). Decomposing it into irreducible representations is almost all of the practical work of group theory.

Derivation: The reduction formula

Let $\chi(R)$ be the character of a reducible representation $\Gamma$. By block diagonalization, $\Gamma$ decomposes into a direct sum of irreducible representations. If $\Gamma^{(i)}$ appears $a_i$ times ($a_i$ is a nonnegative integer), then by the additivity of characters

$$ \chi(R) = \sum_i a_i\,\chi^{(i)}(R) $$

Multiply both sides by $\chi^{(j)}(R)^{*}$ and sum over $R$ for the whole group.

$$ \sum_R \chi^{(j)}(R)^{*}\chi(R) = \sum_i a_i \underbrace{\sum_R \chi^{(j)}(R)^{*}\chi^{(i)}(R)}_{=\,h\delta_{ij}\ (\text{Eq. \eqref{eq:8-orth1-R}})} = a_j\,h $$

The $\delta_{ij}$ collapsed the sum over $i$, leaving only the $i=j$ term. Dividing both sides by $h$ gives

$$ \begin{equation} a_i = \frac{1}{h}\sum_{R\in G}\chi^{(i)}(R)^{*}\,\chi(R) = \frac{1}{h}\sum_{k=1}^{n_c} N_k\,\chi^{(i)}(C_k)^{*}\,\chi(C_k) \label{eq:8-decomp} \end{equation} $$

∎ The second equality merely groups the terms by class (the same operation as in Section 8.2.2).

Caution: $a_i$ is always a nonnegative integer — the strongest check

Since $a_i$ is a count, “how many times $\Gamma^{(i)}$ appears,” it can be neither negative nor a fraction by definition. Therefore, if evaluating Eq. \eqref{eq:8-decomp} gives

  • a fraction → there is a mistake somewhere (forgetting to multiply by $N_k$ is the most frequent cause)
  • a negative number → likewise a mistake
  • a sum of dimensions $\sum_i a_i\ell_i$ that does not match the dimension of $\Gamma$ → a mistake

then one of these has occurred. Conversely, if all the $a_i$ are nonnegative integers and the dimension count also works out, the calculation is almost certainly correct. A group-theory calculation can verify itself through the fact that the answer is an integer—this is a great reassurance when using group theory in practice.

8.8.1 Reducing the three-dimensional representation of $C_{3v}$

Example 8.10: Reducing the representation of $(x,y,z)$ in $C_{3v}$

Reduce the character $\chi^{(xyz)}=(3,\,0,\,1)$ obtained in Example 8.1 by using Table 8.3.

Solution. First we list the numbers to be used: $h=6$, $(N_1,N_2,N_3)=(1,2,3)$, $\chi=(3,0,1)$. All the characters are real, so the complex-conjugate symbol may be dropped.

Coefficient of $A_1$: Since $\chi^{(A_1)}=(1,1,1)$,

$$ a_{A_1} = \frac{1}{6}\Bigl[\,\underbrace{1}_{N_1}\cdot\underbrace{1}_{\chi^{(A_1)}}\cdot\underbrace{3}_{\chi} \;+\; \underbrace{2}_{N_2}\cdot\underbrace{1}_{\chi^{(A_1)}}\cdot\underbrace{0}_{\chi} \;+\; \underbrace{3}_{N_3}\cdot\underbrace{1}_{\chi^{(A_1)}}\cdot\underbrace{1}_{\chi}\Bigr] $$ $$ = \frac{1}{6}\left[3 + 0 + 3\right] = \frac{6}{6} = 1 $$

Coefficient of $A_2$: Since $\chi^{(A_2)}=(1,1,-1)$,

$$ a_{A_2} = \frac{1}{6}\left[1\cdot1\cdot3 + 2\cdot1\cdot0 + 3\cdot(-1)\cdot1\right] = \frac{1}{6}\left[3 + 0 - 3\right] = \frac{0}{6} = 0 $$

Coefficient of $E$: Since $\chi^{(E)}=(2,-1,0)$,

$$ a_{E} = \frac{1}{6}\left[1\cdot2\cdot3 + 2\cdot(-1)\cdot0 + 3\cdot0\cdot1\right] = \frac{1}{6}\left[6 + 0 + 0\right] = \frac{6}{6} = 1 $$

All are nonnegative integers ✓. The conclusion is

$$ \begin{equation} \Gamma^{(xyz)} = A_1 \oplus E \label{eq:8-xyzC3v} \end{equation} $$

Dimension check: $a_{A_1}\ell_{A_1} + a_E\ell_E = 1\cdot1 + 1\cdot2 = 3$. This agrees with the dimension $3$ of the original representation ✓

Check by reconstructing the characters: Adding the characters of $A_1 + E$ component by component gives

$$ (1,1,1) + (2,-1,0) = (3,\,0,\,1) $$

This indeed agrees with $\chi^{(xyz)}$ ✓

Physical reading. $A_1$ is one-dimensional and $E$ is two-dimensional, so one of the three coordinates behaves on its own while the other two behave as a pair. Looking at the “Examples of basis functions” column of Table 8.3, $z$ belongs to $A_1$ and $(x,y)$ belongs to $E$. This agrees perfectly with the intuition that in $C_{3v}$ the principal axis $z$ is treated specially, whereas the in-plane $x,y$ are always mixed by the threefold rotation and so cannot be separated. ∎

Example 8.11: The same thing in $C_{4v}$

Reduce the representation of $(x,y,z)$ in $C_{4v}$.

Solution. First we construct the character. The trace of a three-dimensional rotation is $1+2\cos\phi$, and the trace of a reflection (the two in-plane components cancel as $\pm$, and the one out-of-plane component gives $+1$) is $1$.

$$ \chi(E)=3,\quad \chi(C_4)=1+2\cos90^\circ = 1,\quad \chi(C_2)=1+2\cos180^\circ=-1, $$ $$ \chi(\sigma_v)=1,\quad \chi(\sigma_d)=1 \qquad\Longrightarrow\qquad \chi^{(xyz)} = (3,\,1,\,-1,\,1,\,1) $$

$h=8$, $(N_k)=(1,2,1,2,2)$. We use Table 8.4.

$$ a_{A_1} = \frac18\left[1(1)(3) + 2(1)(1) + 1(1)(-1) + 2(1)(1) + 2(1)(1)\right] = \frac{3+2-1+2+2}{8} = \frac{8}{8} = 1 $$ $$ a_{A_2} = \frac18\left[3 + 2(1)(1) + (1)(-1) + 2(-1)(1) + 2(-1)(1)\right] = \frac{3+2-1-2-2}{8} = \frac{0}{8} = 0 $$ $$ a_{B_1} = \frac18\left[3 + 2(-1)(1) + (1)(-1) + 2(1)(1) + 2(-1)(1)\right] = \frac{3-2-1+2-2}{8} = 0 $$ $$ a_{B_2} = \frac18\left[3 + 2(-1)(1) + (1)(-1) + 2(-1)(1) + 2(1)(1)\right] = \frac{3-2-1-2+2}{8} = 0 $$ $$ a_{E} = \frac18\left[1(2)(3) + 2(0)(1) + 1(-2)(-1) + 2(0)(1) + 2(0)(1)\right] = \frac{6+0+2+0+0}{8} = \frac{8}{8} = 1 $$

Hence

$$ \Gamma^{(xyz)} = A_1 \oplus E \qquad (\text{dimension } 1+2 = 3\ \checkmark) $$

This has exactly the same form as for $C_{3v}$. In the basis column of Table 8.4 as well, $z\to A_1$ and $(x,y)\to E$. For groups of the $C_{nv}$ type, this is always the case when $n\ge3$ (however, for $n\ge5$ there are several two-dimensional irreducible representations $E_1,E_2,\dots$, and $(x,y)$ belongs to $E_1$). Only $n=2$ is an exception: $C_{2v}$ is an abelian group and so has no two-dimensional irreducible representation, and as in Exercise 8.1(5), $\Gamma^{(xyz)}=A_1\oplus B_1\oplus B_2$ splits into three one-dimensional representations. ∎

Example 8.12: Detecting a mistake

A student forgot to multiply by the weights $N_k$ in Example 8.10 and calculated

$$ a_{A_1} \overset{?}{=} \frac16\left[1\cdot3 + 1\cdot0 + 1\cdot1\right] = \frac{4}{6} = \frac{2}{3} $$

Explain what happened.

Solution. $2/3$ is not an integer. Since $a_i$ in Eq. \eqref{eq:8-decomp} is a count, “how many times the irreducible representation appears,” it can never be a fraction. Therefore this is a calculation error.

The cause is that $N_k$ was not multiplied in when using the class-grouped form \eqref{eq:8-decomp}. The original form $a_i = \frac1h\sum_R(\cdots)$ is a sum over all the elements of the group, and when grouping by class we must multiply by $N_k$ to account for the fact that “the same value occurs $N_k$ times.”

Forgetting to multiply by $N_k$ is the most common error in group-theory calculations. When a fraction appears, suspect $N_k$ first. ∎

8.8.2 Calculation techniques for practical use

Physical Meaning: Only the atoms that do not move need to be counted

When we treat molecular vibrations and lattice vibrations in Chapter 10, we need the character of the “$3N$-dimensional representation obtained by giving each of the $N$ atoms displacements in $x,y,z$.” Writing down a $3N\times3N$ matrix is laborious, but in fact we hardly need to calculate anything.

Suppose that under a symmetry operation $R$ an atom $\alpha$ is moved to another location (an atom $\beta\ne\alpha$). Then the $x,y,z$ block of this atom does not appear among the diagonal blocks of the matrix, so it does not contribute to the trace. The only contributions to the trace come from the atoms that stay in place under $R$.

Therefore, if we write the number of atoms left fixed by $R$ as $N_{\mathrm{unmoved}}(R)$ and the trace of the $3\times3$ matrix per atom as $\chi_{3\mathrm{D}}(R)=\pm1+2\cos\phi$ (the double sign applies only to the constant term: $+1$ for a proper rotation $C(\phi)$ and $-1$ for an improper rotation $S(\phi)$), then

$$ \begin{equation} \chi^{(3N)}(R) = N_{\mathrm{unmoved}}(R)\times \chi_{3\mathrm{D}}(R) \label{eq:8-unmoved} \end{equation} $$

is all we need. Concretely, $\chi_{3\mathrm{D}}=3$ for $E$, $-1$ for $C_2$, $0$ for $C_3$, $1$ for $C_4$, $1$ for a reflection $\sigma=S(0^\circ)$, $-3$ for the inversion $i=S(180^\circ)$, $-2$ for $S_3$, $-1$ for $S_4$, and $0$ for $S_6$. For $\mathrm{NH_3}$ ($C_{3v}$, four atoms), under $E$ all four atoms are unmoved, so $\chi=4\times3=12$; under $C_3$ only the N atom is unmoved, so $\chi=1\times0=0$; under $\sigma_v$ the N atom and one H atom on the mirror plane are unmoved, so $\chi=2\times1=2$. This alone gives $\chi^{(12)}=(12,0,2)$. We will use it in Chapter 10.

Example 8.13: Reducing the $12$-dimensional representation of $\mathrm{NH_3}$

Reduce the $\chi^{(12)}=(12,\,0,\,2)$ obtained above into irreducible representations of $C_{3v}$.

Solution. $h=6$, $(N_k)=(1,2,3)$.

$$ a_{A_1} = \frac16\left[1(1)(12)+2(1)(0)+3(1)(2)\right] = \frac{12+0+6}{6} = \frac{18}{6} = 3 $$ $$ a_{A_2} = \frac16\left[12 + 0 + 3(-1)(2)\right] = \frac{12-6}{6} = 1 $$ $$ a_{E} = \frac16\left[1(2)(12) + 2(-1)(0) + 3(0)(2)\right] = \frac{24}{6} = 4 $$ $$ \therefore\quad \Gamma^{(12)} = 3A_1 \oplus A_2 \oplus 4E $$

Dimension check: $3(1) + 1(1) + 4(2) = 3+1+8 = 12$ ✓ All are nonnegative integers ✓

Subtracting from this the translations ($\Gamma^{(xyz)}=A_1\oplus E$, Eq. \eqref{eq:8-xyzC3v}) and the rotations ($A_2\oplus E$ in $C_{3v}$), we obtain

$$ \Gamma^{\text{vibration}} = 3A_1\oplus A_2\oplus 4E \ominus (A_1\oplus E) \ominus (A_2\oplus E) = 2A_1 \oplus 2E $$

The dimension is $2(1)+2(2)=6=3N-6$ ($N=4$), which agrees with the number of vibrational degrees of freedom of a nonlinear molecule ✓ The four normal modes of ammonia (two of $A_1$ and two of $E$; since $E$ is twofold degenerate, the number of modes is $2+2\times2=6$) have come out of the character table alone. ∎

Supplement: $g/u$ and $'/''$ are used exclusively

The symbols $g/u$ are attached only to groups that have an inversion center, and $'/''$ only to groups that have $\sigma_h$ but no inversion center (such as $C_{3h}$ and $D_{3h}$). In groups that have both (such as $D_{6h}$), $g/u$ takes precedence and $'/''$ is not used.

Also, whether the criterion for $_1/_2$ is “$\sigma_v$” or “$C_2'$” depends on the group. In groups that have both (such as $D_{4h}$), $C_2'$ takes precedence. Since this is largely a matter of convention, in delicate cases it is enough to look at the column headings of the character table and decide.

Moreover, the groups of the cubic crystal system ($T$, $T_h$, $T_d$, $O$, $O_h$) have no unique principal axis, so this $\sigma_v$/$C_2'$ rule cannot be applied to them in the first place. The subscripts of $T_1$/$T_2$ are a conventional naming based on symmetry or antisymmetry under $C_4$ for $O$ and $O_h$ and under $S_4$ for $T_d$ ($T_1$ if $\chi=+1$, $T_2$ if $-1$). Indeed, $T_{1u}$ of $O_h$ has $\chi(6C_2')=-1$, so taking $C_2'$ as the criterion would make it $T_2$.

Example 8.14: Actually reading the symbols

(a) $B_2$ of $C_{4v}$ (Table 8.4: $1,-1,1,-1,1$). Since $\chi(E)=1$, it is one-dimensional, so $A$ or $B$. The character of the principal axis $C_4$ is $-1$, so it is $B$. The character of $\sigma_v$ is $-1$ (antisymmetric), so the subscript is $2$. Together, $B_2$. The basis function is $xy$, and indeed a $90^\circ$ rotation changes its sign, $xy\to(-y)(x)=-xy$ (antisymmetric under $C_4$), and the reflection $x\to-x$ in the $yz$ plane also changes its sign, $xy\to-xy$ (antisymmetric under $\sigma_v$). This agrees with the symbol.

(b) $E_g$ of $O_h$ (Table 8.7). Since $\chi(E)=2$, it is two-dimensional, and the symbol is $E$. Since $\chi(i)=2=+\ell$, it is symmetric under inversion → $g$. The basis functions are $(d_{z^2},\,d_{x^2-y^2})$; the $d$ orbitals have $l=2$, so inversion multiplies them by $(-1)^2=+1$, and they are indeed $g$.

(c) $T_{1u}$ of $O_h$. $\chi(E)=3$ gives three-dimensional, and $\chi(i)=-3=-\ell$ gives $u$. The basis is $(x,y,z)$, which becomes $(-x,-y,-z)$ under inversion, so the sign changes. $u$ is correct. The subscript $1$ comes from the fact that the character of $6C_4$ is $+1$ (= behavior symmetric under $C_4$). Since the cubic groups have no unique principal axis, here we follow not the $\sigma_v$/$C_2'$ rule of Table 8.8 but the $C_4$-based convention described in the Supplement above (taking $\chi(6C_2')=-1$ as the criterion would give $T_2$).

(d) $A_2''$ of $D_{3h}$. It is one-dimensional and symmetric under the principal axis $C_3$, so $A$; antisymmetric under $C_2'$, so the subscript is $2$; antisymmetric under $\sigma_h$, so the prime is double. The basis function is $z$ (the out-of-plane direction of a planar molecule changes sign under both the in-plane $C_2'$ and the reflection $\sigma_h$ in the plane). ∎

Caution: The double meaning of the symbol $E$

The letter $E$ is used in group theory with two entirely different meanings.

  • $E$ as the identity operation (German Einheit)—it appears in the column headings of a character table.
  • $E$ as a two-dimensional irreducible representation (German entartet = degenerate)—it appears in the row headings of a character table.

At the intersection of the $E$ row and the $E$ column in Table 8.3 is written $2$; this means “the character of the identity operation in a two-dimensional irreducible representation = the dimension = 2.” It is easy to get confused until you are used to it, but you can tell them apart by whether it is in a row or a column.

In this book, wherever possible, we write the identity operation as $E$ and the irreducible representation as $\Gamma^{(i)}$ or the $E$ representation, so as to avoid misunderstanding.

8.10 Summary and Exercises

8.10.1 Summary

  • The character $\chi(R)=\Tr D(R)$ is invariant under a similarity transformation (Theorem 8.1) and takes the same value on all elements of the same class (Theorem 8.2). The $h\ell^2$ numbers are compressed into as many values as there are classes. $\chi(E)=\ell$ (the dimension of the representation).
  • The first orthogonality relation: $\sum_k N_k\chi^{(i)}(C_k)^{*}\chi^{(j)}(C_k)=h\delta_{ij}$. It follows simply by setting $\mu=\nu$ and $\alpha=\beta$ in the great orthogonality theorem and summing. It means that the rows of the character table, with the weight $\sqrt{N_k/h}$, are orthonormal vectors.
  • The regular representation: the $h$-dimensional representation whose basis is the group elements themselves, with $\chi^{\mathrm{reg}}(R)=h\delta_{R,E}$. It contains $\Gamma^{(i)}$ exactly $\ell_i$ times, and counting dimensions re-derives $\sum_i\ell_i^2=h$.
  • Number of irreducible representations = number of classes (Theorem 8.3). The inequality $\le$ follows from the orthogonality of the rows, and $\ge$ follows from “the only class function orthogonal to all the characters is zero” (Schur's first lemma plus the regular representation). Hence the character table is square.
  • The second orthogonality relation: $\sum_i \chi^{(i)}(C_k)^{*}\chi^{(i)}(C_{k'})=(h/N_k)\delta_{kk'}$. It is exactly the linear-algebra fact that if the rows of a square matrix are orthonormal, then so are its columns. It differs from the first orthogonality relation in that the weight $N_k$ is not multiplied.
  • How to construct a character table (Figure 8.3): ① write down the elements → ② divide them into classes → ③ solve $\sum\ell_i^2=h$ in integers → ④ the identity representation → ⑤ the simultaneous equations from the first orthogonality relation → ⑥ check. We completed $C_{3v}$, $C_{4v}$, and $O$ by this procedure.
  • The direct product: $O_h=O\otimes\{E,i\}$. Since $\chi^{(a\times b)}=\chi^{(a)}\chi^{(b)}$, a $10\times10$ table can be built mechanically from a $5\times5$ table. $g$ means $\chi(i)=+\ell$, and $u$ means $-\ell$.
  • Reduction: $a_i=\frac1h\sum_k N_k\chi^{(i)}(C_k)^{*}\chi(C_k)$. Since $a_i$ is always a nonnegative integer, a fraction or a negative number signals a calculation error (forgetting to multiply by $N_k$ is the most frequent). Also check the dimension count $\sum_i a_i\ell_i=\ell$.
  • Test of irreducibility: the representation is irreducible if $\frac1h\sum_k N_k\abs{\chi(C_k)}^2=1$; the general formula is that this quantity $=\sum_i a_i^2$.
  • Mulliken symbols: $A/B$ denote one-dimensional representations that are symmetric/antisymmetric under the principal axis, $E$ denotes a two-dimensional representation, and $T$ a three-dimensional one. The subscripts $1/2$ give the sign under $\sigma_v$ (or $C_2'$), $g/u$ give the sign under inversion, and $'/''$ give the sign under $\sigma_h$. The one exception is $T_1/T_2$ of the cubic groups, which have no principal axis; there the convention is to refer to $C_4$ (to $S_4$ in $T_d$).

Taking the products gives $\chi^{(12)}=(12,0,-2,4,-2,2)$. The reduction gives $A_1'\oplus A_2'\oplus 3E'\oplus 2A_2''\oplus E''$ (dimension $1+1+6+2+2=12$ ✓). Removing the translations $E'\oplus A_2''$ and the rotations $A_2'\oplus E''$ leaves $\Gamma^{\text{vibration}}=A_1'\oplus 2E'\oplus A_2''$, of dimension $1+4+1=6=3N-6$ ✓.

Exercise 8.3: Decomposing the $d$ orbitals in a $C_{3v}$ field

The spherical harmonics $\{Y_{lm}\}$ ($2l+1$ of them) of angular momentum $l$ have, under a rotation through the angle $\phi$, the character

$$ \chi_l(\phi) = \frac{\sin\left[\left(l+\tfrac12\right)\phi\right]}{\sin\left(\phi/2\right)} $$

(derived in Chapter 9). Under inversion, $\chi_l(iR)=(-1)^l\chi_l(R)$.

(1) For $l=2$ ($d$ orbitals), find the character for each class of $C_{3v}$.

(2) Reduce the representation and state how the $d$ orbitals split in a $C_{3v}$-symmetric field.

(3) Write down the degeneracies of the split levels and verify that $1+2+2=5$.

Hint: (1) $\chi_2(E)=\lim_{\phi\to0}$ gives $2l+1=5$. For $\chi_2(C_3)$: with $\phi=120^\circ$, $\sin(2.5\times120^\circ)/\sin60^\circ=\sin300^\circ/\sin60^\circ=(-\sqrt3/2)/(\sqrt3/2)=-1$. Since we can write $\sigma_v=i\,C_2$, $\chi_2(\sigma_v)=(-1)^2\chi_2(C_2)=\sin(2.5\times180^\circ)/\sin90^\circ=\sin450^\circ=1$. Hence $(5,-1,1)$. (2) $a_{A_1}=\frac16[5+2(-1)+3(1)]=1$, $a_{A_2}=\frac16[5-2-3]=0$, $a_E=\frac16[2(5)+2(-1)(-1)+0]=\frac{12}{6}=2$. Hence $\Gamma_d = A_1\oplus 2E$. (3) There is one nondegenerate level and two twofold-degenerate levels. $1+2+2=5$ ✓ The fivefold-degenerate $d$ level splits into three levels.

Exercise 8.4: Actually decomposing the regular representation

(1) Write down the character of the regular representation (six-dimensional) of $C_{3v}$ and reduce it using Table 8.3.

(2) Verify that the result satisfies $a_i=\ell_i$, and show that the dimension count works out.

(3) Do the same for $C_{4v}$ (eight-dimensional).

Hint: (1) $\chi^{\mathrm{reg}}=(6,0,0)$. $a_{A_1}=\frac16[1(1)(6)+2(1)(0)+3(1)(0)]=1$, $a_{A_2}=\frac16[6]=1$, $a_E=\frac16[1(2)(6)]=2$. Hence $\Gamma^{\mathrm{reg}}=A_1\oplus A_2\oplus 2E$. (2) It agrees with $\ell_{A_1}=1$, $\ell_{A_2}=1$, $\ell_E=2$ ✓. The dimension is $1+1+2\times2=6$ ✓. (3) $\chi^{\mathrm{reg}}=(8,0,0,0,0)$, and $\Gamma^{\mathrm{reg}}=A_1\oplus A_2\oplus B_1\oplus B_2\oplus 2E$, of dimension $1+1+1+1+4=8$ ✓.

Exercise 8.5: A group of prime order is always abelian, and all its irreducible representations are one-dimensional

For a group $G$ of order $h=p$ (a prime number), show the following.

(1) $G$ is a cyclic group and is abelian.

(2) The number of classes is $p$ (every element forms a class by itself).

(3) There are $p$ irreducible representations, and all are one-dimensional.

(4) With $\omega = e^{2\pi i/p}$, show that the character table is given by $\chi^{(m)}(a^n)=\omega^{mn}$ ($m,n=0,1,\dots,p-1$).

Hint: (1) Take an element $a$ other than $E$. The order of the cyclic subgroup generated by $a$ is a divisor of $p$ by Lagrange's theorem, and it is not $1$, so it is $p$. Hence $G=\{E,a,a^2,\dots,a^{p-1}\}$ is cyclic, and a cyclic group is abelian. (2) In an abelian group $XAX^{-1}=A$, so every element forms a class by itself. $n_c=p$. (3) By Theorem 8.3, $n_r=p$; by Eq. \eqref{eq:8-dimsum}, $\sum_{i=1}^{p}\ell_i^2=p$; and since $\ell_i\ge1$, all $\ell_i=1$. (4) In a one-dimensional representation, $\chi(a)^p=\chi(a^p)=\chi(E)=1$, so $\chi(a)$ is a $p$th root of $1$. The $p$ choices correspond to exactly $p$ representations. Check of the second orthogonality relation: $\sum_m \omega^{-mn}\omega^{mn'}=\sum_m\omega^{m(n'-n)}=p\,\delta_{nn'}$ (the sum of a geometric series), which agrees with $h/N_k=p/1=p$ ✓

Exercise 8.6: An application of the second orthogonality relation — finding the number of elements in a class

Suppose that the $k$th column of the character table of some group is $(1,-1,0,1,-1)$ (in the order $A_1,A_2,E,T_1,T_2$ from the top, with dimensions $1,1,2,3,3$).

(1) Use the case $k=k'$ of Eq. \eqref{eq:8-orth2} to find the number of elements $N_k$ of this class (find $h$ from Eq. \eqref{eq:8-dimsum}).

(2) Use Eq. \eqref{eq:8-colcheck} to verify that this column is not the column of the identity element.

Hint: (1) $h=\sum\ell_i^2=1+1+4+9+9=24$. The squared length of the column is $1+1+0+1+1=4$. This equals $h/N_k$, so $N_k=24/4=6$. From the combination of dimensions $(1,1,2,3,3)$ and $h=24$, we see that this group is $O$ (or $T_d$, which has the same character table). There are two classes with $6$ elements, $6C_4$ and $6C_2'$, but comparing with Table 8.6, $T_1$ is $+1$ and $T_2$ is $-1$, so this is the column of $6C_4$ (if read as $T_d$, the corresponding column is $6S_4$). (2) $\sum_i\ell_i\chi^{(i)}(C_k)=1(1)+1(-1)+2(0)+3(1)+3(-1)=0$. For the column of the identity element this would have to be $h=24$, so this is indeed not the column of $E$ ✓
