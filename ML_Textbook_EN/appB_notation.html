Appendix BList of Symbols, Terminology Correspondence, and Key Equations

This book uses many symbols over its 28 chapters. Each symbol is defined where it first appears, but if you start reading from a middle chapter, or want to compare equations from different chapters, hunting for the definitions is a nuisance. This appendix is a quick-reference table for exactly that purpose.

Section B.1 is the list of symbols, organized by field in tables, with one final table collecting the symbols whose meaning changes from chapter to chapter. It is unavoidable that the same letter represents different quantities in different chapters (the number of letters is limited, and each field has its own conventions). If an equation does not seem to make sense, look at this table first. Section B.2 is a table comparing the notation with that of C. M. Bishop's Pattern Recognition and Machine Learning (PRML), for readers who read it alongside this book. Section B.3 is a table of Japanese and English terms, Section B.4 is the list of the probability distributions treated in Chapter 3 together with their conjugate priors, and Section B.5 is a list of the key equations of each chapter.

The “first appearance” in the tables is a link to the section where the symbol or term is defined or introduced (“8.1” means Chapter 8, Section 8.1). (If the same symbol is used with a different meaning in a later chapter, see the table in Section B.1.12.) The equations in Section B.5 are copied from the main text of each chapter without changing the symbols, with a link to the section in place of an equation number. Check the derivations and the assumptions of the equations in the main text at the linked section.

B.1 List of Symbols

B.1.1 Notational conventions

  • Vectors and matrices: A vector is a bold lowercase letter $\bm{x}$ and is a column vector; a matrix is a bold uppercase letter $\bm{X}$. The transpose is $\bm{x}^{\tp}$. The size is written as a set, as in $\bm{\Phi}\in\R^{N\times M}$ ($N$ rows and $M$ columns). Only in Chapters 24–26 (attention, the Transformer, and GPT), however, following the original papers, we use the matrix whose rows are the elements of a sequence, $\bm{X}\in\R^{T\times d_{\mathrm{model}}}$, and multiply linear transformations from the right ($\bm{X}\bm{W}$).
  • Probability: A random variable and its value are written with the same lowercase letter. The probability mass function and the probability density function are both written $p(\cdot)$, and the probability of an event is $P(\cdot)$. A condition is written with a vertical bar, $p(x\mid y)$, and a probability conditioned on the data always carries $\mid\data$. The second argument of the Gaussian distribution $\Normal(x\mid\mu,\sigma^{2})$ is the variance.
  • Logarithms: The natural logarithm is $\ln$. Only when information is counted in bits do we use $\log_2$.
  • Noise and prior distributions: Observation noise is written with the variance $\sigma^{2}$ (the precision $\beta$ is not used), and $\beta$ is reserved for the inverse temperature $1/(k_{\mathrm B}T)$ of statistical mechanics. The variance of the prior distribution of the weights is $\sigma_w^{2}$.
  • Target values: The supervisory signal is $y$ (PRML's $t$). The symbol $t$ is used for time and for position in a sequence.
  • Loss: The loss is $L$ (we do not write $E(\bm{w})$; $E$ is energy and $\Ex$ is the expectation (expected value)). Some chapters write it as a sum over the data and others as a mean, so the meaning of the magnitude of the regularization coefficient $\lambda$ differs by a factor of $N$ (Table B.12).

B.1.13 Chapters that write the loss as a sum and chapters that write it as a mean

Whether the loss is written as a sum or as a mean over the data does not change the minimizer, but the gradient and the Hessian matrix differ by a factor of $N$. For this reason the size of one step changes even with the same learning rate $\eta$, and the regularization coefficient $\lambda$ in the mean convention also corresponds to $1/N$ of its value in the sum convention.

B.4.2 Conjugate prior pairs

The parameters of the prior distribution can be read as “the number of pseudo-observations.” For example, the beta prior distribution $\mathrm{Beta}(a,b)$ has the same form as the posterior distribution obtained by starting from the uniform $\mathrm{Beta}(1,1)$ and observing $a-1$ successes and $b-1$ failures, so $a-1,\ b-1$ are read as the pseudo-counts contained in the prior distribution (Chapter 4, Section 4.4).
