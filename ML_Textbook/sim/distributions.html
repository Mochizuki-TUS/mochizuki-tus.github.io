確率分布 — 分布の形，区間確率，標本平均の振る舞い

二項・Poisson・Gauss・Cauchy（Lorentz 型）・Gamma・Beta・Student の t・Weibull 分布の形を描き，区間に入る確率を累積分布関数から求めます．平均・分散が存在しない分布があること，半値全幅が同じでも Gauss 分布と Cauchy 分布では裾の重さがまったく違うことを確かめてください．②では，標本を増やすと Gauss 分布の標本平均は落ち着くのに，Cauchy 分布の標本平均は落ち着かない（中央値は落ち着く）ことを見ます．

確率密度関数（離散なら確率質量関数）と区間確率

塗った面積が区間に入る確率 P(x1 ≤ x ≤ x2) です．値は下の累積分布関数の差 F(x2) − F(x1) から求めます．

累積分布関数 F(x) = P(X ≤ x)．縦の矢印の長さが F(x2) − F(x1)，つまり上の図の塗った面積です．離散分布では F は階段になり，区間は端の整数を含みます．

操作手順と観察する点

  1. ①を既定のまま（Gauss 分布 𝒩(x | 0, 12)，区間 [−1, 1]）で開きます．見る点：塗った面積 P(−1 ≤ x ≤ 1) = Φ(1) − Φ(−1) = 0.8413 − 0.1587 = 0.6827．区間の操作で「±2 標準偏差」を押すと 0.9545，平均・分散・半値全幅 2√(2 ln 2) σ = 2.355 も読み出しで確かめます．
  2. 「比べる例」の「Gauss と Cauchy（半値全幅をそろえる）」を押し，「縦軸を対数にする」と「横軸を広く（裾を見る）」をオンにします．見る点：ピークの幅は同じでも，Cauchy 分布の裾は 1/x2 でしか減らず，Gauss 分布は急に落ちること．P(−1 ≤ x ≤ 1) は Gauss 0.6827，Cauchy 0.4482．読み出しで Cauchy の平均・分散が「存在しません」と理由つきで出ること．
  3. 分布を Cauchy 分布にして，標本を「1000 個」引きます．見る点：ヒストグラムは密度の形に合うのに，標本平均は 5.33（seed 20261112）と中心 0 から大きく外れ，標本分散は 1.1×105 にもなること．範囲外の点がいくつあるか．中央値は −0.048 と中心に近いこと．
  4. 「比べる例」の「t（ν）と Gauss」を押し，自由度 ν のスライダーを 1 から 1000 まで動かします．見る点：ν = 1 で Cauchy 分布と同じ形，ν が大きいと Gauss 分布に近づくこと．平均は ν > 1，分散は ν > 2 でだけ存在すること（ν = 3 で分散 3，ν = 30 で 1.071）．
  5. ②を開きます（既定：n は 104 まで，5 系列，seed 20261112）．見る点：左の Gauss 分布の標本平均は ±σ/√n の帯の中へ縮んでいくのに，右の Cauchy 分布の標本平均はときどき大きく跳び，n = 104 でも 0.769，−1.83，0.118，1.35，−0.910 とばらばらであること（5 系列中 2 系列が |x̄ − x0| > γ）．
  6. ②で「描く量」を「中央値」にします．見る点：Cauchy 分布でも中央値は落ち着き，±πγ/(2√n) の帯（n = 104 で ±0.0157）に入っていくこと．「同じ seed でやり直す」を押しても曲線が変わらないこと．

計算している式とアルゴリズム

区間確率は確率密度関数 p(x) の積分で，累積分布関数 F の差として計算します．離散分布では端の整数を含む和です．

P(x1≤x≤x2)=∫x1x2p(x)dx=F(x2)−F(x1),離散：∑k=⌈x1⌉⌊x2⌋p(k)

各分布の密度（質量）関数と，平均・分散（存在するときだけ）：

二項：p(x)=(Nx)μx(1−μ)N−x,𝔼[x]=Nμ,Var[x]=Nμ(1−μ) Poisson：p(x)=λxe−λx!,𝔼[x]=Var[x]=λ Gauss：𝒩(x∣μ,σ2)=12πσ2exp(−(x−μ)22σ2),F(x)=Φ(x−μσ),半値全幅22ln2σ Cauchy：p(x)=1πγ(x−x0)2+γ2,F(x)=12+1πarctanx−x0γ,半値全幅2γ Gamma：Gam(x∣a,b)=baxa−1e−bxΓ(a),𝔼[x]=ab,Var[x]=ab2（b は率） Beta：Beta(x∣a,b)=Γ(a+b)Γ(a)Γ(b)xa−1(1−x)b−1,𝔼[x]=aa+b,Var[x]=ab(a+b)2(a+b+1) Student の t：p(x)=Γ((ν+1)/2)Γ(ν/2)νπs[1+(x−μ)2νs2]−(ν+1)/2,𝔼[x]=μ(ν>1),Var[x]=s2νν−2(ν>2) Weibull：F(s)=1−exp[−(s/s0)m],𝔼[s]=s0Γ(1+1/m)

Cauchy 分布の平均が存在しないのは，x0 の両側 R までで切った積分が R → ∞ で発散するからです（主値は x0 ですが，期待値の定義 ∫|x| p(x) dx < ∞ を満たしません）．

∫x0−Rx0+R|x−x0|p(x)dx=γπln(1+R2γ2),∫x0−Rx0+R(x−x0)2p(x)dx=2γπ[R−γarctanRγ]

②の標本平均 x̄n = (x1 + ⋯ + xn)/n について，分散 σ2 が有限なら Var[x̄n] = σ2/n で，帯 ±σ/√n に入る確率は n が大きいとき約 68 % です．Cauchy 分布では特性関数 𝔼[eikx] = eix0k − γ|k| から

𝔼[eikx¯n]=(eix0k/n−γ|k|/n)n=eix0k−γ|k|⇒x¯n∼Cauchy(x0,γ)

となり，n によらず |x̄n − x0| > γ となる確率は 1/2 のままです．一方，中央値は（中央値での密度 p(m) > 0 なら）近似的に標準偏差 1/(2p(m)√n) で縮みます：Gauss では σ√(π/2)/√n，Cauchy では πγ/(2√n)．

数値計算：累積分布関数は正則化不完全ベータ関数・ガンマ関数（連分数），誤差関数，arctan で計算します（共有ライブラリ MLCore）．画面の「数値積分による確認」は，密度関数を分位点で区切った小区間ごとに二重指数型（tanh–sinh）の数値積分で求めた値で，累積分布関数の差と比べるためのものです．②の標本平均は補正つきの和（Kahan），中央値は二つのヒープによる逐次の中央値です．

データと乱数の条件

  • ①の標本と②の系列は，選んだ分布から引いた教育用の合成データです（実在の測定値ではありません）．量は無次元です（Weibull 分布の s は尺度 s0 と同じ単位の強度と読めます）．
  • 乱数は seed つきの生成器（mulberry32）です．既定の seed は ①，② とも 20261112．Gauss 乱数は Box–Muller 法，Cauchy 乱数は tan(π(u − 1/2))，t 乱数は z/√(g/ν)（z は標準 Gauss，g は自由度 ν の χ2）で作ります．
  • ①の標本は，パラメーターを変えるたびに同じ seed から引き直します（seed が同じなら同じ一様乱数の列から作られます）．
  • ②の系列 j の乱数は seed と j から作るので，n の上限や系列の数を変えても各系列の初めの部分は同じです．同じ seed でやり直すと同じ曲線になります．
  • 上限：①の標本は 10000 個，②は n ≤ 105，系列は 20 本まで（最大 2×106 個 × 2 分布）．②の計算は 12 ms ずつに分けて進め，途中で止められます．曲線は n の対数で等間隔な点（n の上限が 103，104，105 のとき 151，180，197 点）で記録します．

簡略化している点

  • パラメーターの範囲を制限しています（例：Gauss の μ ∈ [−5, 5]，σ ∈ [0.1, 5]，二項の N ≤ 200）．t 分布の自由度は 0.5〜1000 の 17 通りから選びます．
  • ①のヒストグラムは描く範囲の中だけで数え，範囲外の個数は読み出しに書きます．
  • ②では位置を 0 に固定し，尺度（Gauss の σ，Cauchy の γ，t の s）を共通のスライダーで変えます．Gauss・Cauchy の半値全幅はそろえていません（尺度パラメーターをそろえています）．
  • 中央値の帯 ±1/(2p(m)√n) は n が大きいときの近似です．

結果が不安定になる条件

  • Cauchy 分布や ν ≤ 2 の t 分布の標本では，まれに非常に大きな値（105 以上）が出て，標本平均・標本分散が大きく跳びます．これは計算の誤りではなく分布の性質です．
  • Gamma（a < 1），Beta（a < 1 または b < 1），Weibull（m < 1）では，定義域の端で密度が発散します（面積は有限）．図では枠の上に出た部分を切って描きます．端で密度が発散する区間の数値積分は，倍精度で端に近づける限界のため 10−8 程度ずれることがあります．
  • 縦軸を対数にすると，裾の非常に小さな確率（10−300 程度より下）は 0 に丸まり，線が途切れます．
  • NaN・無限大が出たら計算を止めて理由を表示します．

操作後に答える短い問い

  1. Gauss 分布 𝒩(x | 0, 1) と，半値全幅をそろえた Cauchy 分布（γ = √(2 ln 2) ≈ 1.177）で，P(−1 ≤ x ≤ 1) と P(|x| > 3) はそれぞれいくつですか．
    答えの例

    P(−1 ≤ x ≤ 1) は Gauss 0.6827，Cauchy (2/π) arctan(1/1.177) = 0.4482．P(|x| > 3) は Gauss 0.0027 に対して Cauchy 0.2381 で，約 88 倍です（|x| > 5 では 5.7×10−7 と 0.147）．ピークの幅が同じでも，Cauchy 分布は確率の多くを裾に持っています．スペクトル線形を Gauss 型で当てはめると，この裾の強度を取りこぼします．

  2. Cauchy 分布（γ = 1）の平均が存在しないことを，読み出しの部分積分の値で説明してください．
    答えの例

    ∫|x − x0| p(x) dx を ±R で切ると (γ/π) ln(1 + R2/γ2) で，R = 10，100，1000，106 で 1.47，2.93，4.40，8.80 と，R を 10 倍するたびに約 1.47 ずつ増え続けます（対数発散）．p(x) が 1/x2 でしか減らないので x p(x) ～ 1/x の積分が収束しません．

  3. ②の既定（n ≤ 104，5 系列，seed 20261112，尺度 1）で，n = 104 の標本平均は Gauss と Cauchy でそれぞれどのくらい散らばっていますか．理論とどう対応しますか．
    答えの例

    Gauss は −0.0035，0.0006，−0.0087，0.0075，0.0137 で，理論の標準偏差 σ/√n = 0.01 程度に収まります．Cauchy は 0.769，−1.83，0.118，1.35，−0.910 で，5 系列中 2 系列が |x̄| > γ = 1 です（n = 103 では 5.33 という大きな値の系列もあります）．x̄n は n によらず Cauchy(x0, γ) に従い，|x̄n − x0| > γ の確率はいつも 1/2 です．同じ標本の中央値は 0.0057，0.0022，0.0052，0.0005，0.0036 で，πγ/(2√n) = 0.0157 の範囲に入っています．

  4. t 分布で ν = 1，2，3，30 のとき，平均と分散はそれぞれどうなりますか．
    答えの例

    ν = 1：平均・分散とも存在しません（Cauchy 分布と同じ）．ν = 2：平均 μ は存在しますが分散は発散します．ν = 3：分散 s2ν/(ν − 2) = 3．ν = 30：30/28 = 1.071 で，Gauss 分布（分散 1）に近づきます．
